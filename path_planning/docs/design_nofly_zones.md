# 禁飞区约束下的控制网络路径规划 —— 时空扩展设计

> 状态：设计定稿（2026-10-28）。基线方法：Lin 等 (2021) 两阶段控制网络
> （`paper/reference/Lin 等 - 2021 - Trajectory planning … A control networ.pdf`）。
>
> **阶段范围**：只处理禁飞区**可行性约束**（静态永久 + 动态临时）。
> **TPR 风险暂不引入**：综合代价中其权重置 0（槽位保留），列为未来拓展（§10）。

## 0. 问题定义

在 Lin 等 (2021) 的控制网络路径规划框架上引入**显式时空网络**，使无人机规划出的连续飞行轨迹
在整个飞行过程中满足动态禁飞区约束。三个子问题：

1. **空间约束**：二维禁飞区与控制网络节点、边及连续轨迹之间如何判定冲突；
2. **时间约束**：禁飞区的空间范围和有效时间均可能变化，如何确定一条边在实际飞行期间是否可用；
3. **时空搜索**：如何将到达时间纳入搜索状态，并保证最终路径经轨迹平滑后仍满足禁飞区约束。

关键不是"在空间图里删掉禁飞区内的节点"，而是承认**同一条边在不同时刻可用性不同**，
并把最终判据落在连续轨迹上。

## 1. 总体框架：空间控制网络 → 时空控制网络

保留 Lin 的"离线建网 + 在线搜索 + 平滑 + 轨迹生成"总结构，将空间图扩展为时空图。五个模块：

| 模块 | 职责 | 阶段 |
|------|------|------|
| 1 基础控制网络构建 | 节点与可行连接边；处理**静态永久禁飞区** | 离线一次 |
| 2 动态禁飞区时空建模 | 二维范围、有效时间窗及其变化、版本化 | 在线更新 |
| 3 时空网络扩展 | 节点扩展为"虚拟节点 × 时间层" | 按规划时域在线 |
| 4 时空路径搜索 | 整边时空占用检查 + 最短到达搜索 | 在线（每 OD） |
| 5 连续轨迹生成与复核 | 平滑离散路径，对最终连续轨迹再做时空碰撞检测 | 在线（每 OD） |

边界：**模块 1 离线构建、长期复用；模块 2–5 在线**。动态禁飞区约束与时空网络
按规划时域在线更新/重建，不进离线产物。

## 2. 数学建模

### 2.1 基础控制网络（继承 Lin）

控制网络 $G_0=(V,E)$：$V$ 控制节点集合，$E$ 有向连接边集合，$e=(u,v)$ 为候选连接，
$\tau_e$ 为沿边飞行时间（由无人机运动约束与边的运动规划模型确定）。

**细化（与 Lin 对齐）**：搜索基图应取 Lin 的**扩展控制网络**——$V$ 为虚拟节点
（运动状态 0..6），$\tau_e$ 按四种虚拟链路情形取最小飞行时间（Lin Eq.(1)-(4)），
转向减速等动力学已含在 $\tau_e$ 中。时空状态定义在虚拟节点上（§3.1），
否则会丢掉 Lin 对运动状态的表达。

对**永久禁飞区**：在基础网络构建阶段预先排除冲突连接。对**临时禁飞区**：
不宜在空间网络建立时永久删除相关边——同一条边可能在某些时段不可用、其他时段可用。

### 2.2 二维动态禁飞区

第 $j$ 个临时禁飞区在时刻 $t$ 的水平投影区域 $\Omega_j(t)\subseteq\mathbb{R}^2$，
有效时间集合 $\mathcal{T}_j=\bigcup_{m=1}^{M_j}[a_{jm},b_{jm})$（左闭右开，便于表达相邻时段启停切换）。

空间范围也随时间变化时，把时间轴划为变化区间，在每个区间内记录：

$$\mathcal{N}_j=\{\,([a_{jm},b_{jm}),\ \Omega_{jm})\,\}$$

- **阶跃变化模型（第一版采用）**：每个时间段一个固定多边形，适合定时启停、临时划设、
  分时段更新；便于复现实验，能明确区分空间变化与时间变化的影响。
- 连续变化模型（边界随时间连续移动）：需额外定义边界插值或运动规律，列未来拓展（§10）。

**建模假设（固定）**：二维禁飞区被视为对**所有规划飞行高度**均有效的水平禁飞区域。
若实际规则允许从禁飞区上方飞越，必须引入高度层或高度适用范围；单独二维模型无法表达此例外（§10）。

### 2.3 安全膨胀

考虑机体尺寸、定位误差与安全间隔：将禁飞区向外膨胀预先设定的安全距离 $d_s$，
记为 $\Omega_j^{+}(t)$，**一切判定对膨胀体进行**：

$$\mathbf{p}_e(\tau)\notin\Omega_j^{+}(t_k+\tau)$$

静态永久禁飞区同样膨胀（法定间隔）。该膨胀是本设计的安全建模措施，并非 Lin 等 (2021) 原文机制。

## 3. 核心设计：显式时空网络

### 3.1 时间离散化

规划时域 $[t_0,T_{\max}]$，时间步长 $\Delta t$，时间层 $t_k=t_0+k\Delta t,\ k=0,\ldots,K$。
时空状态为"虚拟节点 + 时间层"：

$$s=(v,k),\quad v\in V_{\exp},\qquad V^{ST}=\{(v,k)\}$$

同一空间位置在不同时间层是不同的搜索状态（禁飞状态可能已改变）。

### 3.2 时空连接

$(u,k)$ 选原网络边 $e=(u,v)$，预计到达 $t_{\mathrm{arr}}=t_k+\tau_e$。

- 不允许等待：只能连到 $t_{\mathrm{arr}}$ 对应的时间层。取整策略（简单偏保守）：

  $$k'=\left\lceil\frac{t_k+\tau_e-t_0}{\Delta t}\right\rceil$$

  保证离散状态不早于预计到达，但**偏差逐边累积**，实验中必须记录该影响（exp03）。
  **误差控制**：标签内保存**连续到达时间**（精确值），时间层仅用于状态离散与去重；
  最终可行性一律以轨迹生成阶段的实际时间为准（§7）。

- 允许等待：加等待连接 $(v,k)\rightarrow(v,k+1)$，代价 $\Delta t$。两条约束：
  1. 只有**安全等待节点**允许等待（对应 Lin 运动状态 0 的悬停语义位置）；
  2. 等待段自身要过检：$\mathbf{x}_v\notin\Omega^{+}(t),\ \forall t\in[t_k,t_{k+1}]$
     （禁飞区可能在等待期间覆盖该点）。

### 3.3 边的时空可行性判定（最关键）

只判起点终点不够——无人机可能在飞行途中穿过禁飞区。边 $e$ 的水平位置
$\mathbf{p}_e(\tau),\ 0\le\tau\le\tau_e$，从 $t_k$ 出发的时空可行性：

$$\mathbf{p}_e(\tau)\notin\Omega_j^{+}(t_k+\tau),\quad \forall \tau\in[0,\tau_e],\ \forall j$$

实现：禁飞区边界在时间段内固定时用**线段 × 多边形相交**；连续变化模型则按边界运动规律
做时空相交。另有两个易漏情形必须覆盖：

- **节点被禁飞区覆盖**：封锁该节点全部出入边（星形剪枝），而不只是剪穿越边；
- **等待占用**（§3.2）：等待段按"零速度的边"同样过检。

判定点统一收口在 `constraints/query.py`（升级为带时间的占用检查）：
离线静态剪枝与在线时空检查**同一判定口径**。

## 4. 静态永久禁飞区的离线处理（模块 1 细化）

这层是"把禁飞区当建筑"的最小改造，沿 Lin 现有机制扩展：

1. **几何统一**：禁飞区 = 多面体/圆柱 + 法定缓冲的膨胀体，与建筑 cuboid 进同一 `CollisionQuery`
   （Lin Fig.6 的"链路-表面求交即碰撞"推广到任意凸体/圆柱）；
2. **控制点布设**：膨胀体内不布点；禁飞区与建筑间净空 < $d_1$+缓冲 的窄缝宁可不布点
   （防"看似有网、实际不通"）；
3. **链路剪枝**：穿建筑或穿禁飞膨胀体的链路直接删除；
4. **连通域离线预计算**（union-find）：剪枝后网络可能碎裂，在线 OD 两端一点即知可行性，
   省一次搜索；
5. **虚拟控制点补设**：禁飞区两侧绕行代价畸高时，按 Lin 的补设机制加点；
6. **规模报告**：剪枝前后节点/边数进实验记录（消融素材）。

## 5. 搜索算法：时空 Dijkstra / A\*

禁飞区是**硬约束**，通过禁止状态与连接实现，不进代价项（TPR 权重为 0，见 §10）。目标：

$$\min_{\pi}\ T_{\mathrm{arrival}}(\pi)-t_0$$

约束：起点→终点；每条空间连接满足基础运动约束；每条连接在其实际飞行时间段内不与动态禁飞区冲突；
等待仅出现在安全等待节点；最终连续轨迹满足禁飞区约束。（若暂不追求最短时间，也可退化为
"任意可行路径"，约束实现方式不变。）

| 算法 | 作用 | 阶段 |
|------|------|------|
| 时空 Dijkstra | 验证时空网络与约束检查的正确性 | 基线（首选） |
| 时空 A\*（$h(v)=\lVert\mathbf{x}_v-\mathbf{x}_{goal}\rVert/v_{\max}$） | 减少状态扩展量；$h$ 忽略绕行与等待，为可采纳下界 | 第二阶段 |
| 原始空间网络搜索（无动态禁飞） | 不考虑动态禁飞区的对照 | 基准比较 |

```
输入: 扩展控制网络 G0, 起点 s, 终点 g, t0, 动态禁飞区集合 NFZ(版本 r), Δt, T_max
输出: 满足禁飞区约束的时空路径 π, 或无解

1  构建时间层 t_k = t0 + kΔt；状态 = (虚拟节点 v, k)
2  起点状态 (s, 0) 入 OPEN；dist / pred 初始化
3  while OPEN 非空:
4    q = (u, k) ← OPEN.pop()              # Dijkstra 取最小 g；A* 取最小 f = g + h
5    if u == g:
6      π ← 沿 pred 回溯
7      连续轨迹生成 + 时空复核（§7）
8      if 复核通过: return π
9      else: 按修复阶梯处理（偏移收缩 → 局部重搜 → 全量重搜）
10   for 每条出虚拟边 e = (u, v):
11     t_dep ← 标签连续时间；t_arr ← t_dep + τ_e
12     if 整边占用检查失败（∃j, ∃τ∈[t_dep,t_arr]: p_e(τ) ∈ Ω_j^+(τ)）: continue
13     k' ← 层索引(t_arr)；if k' > K: continue
14     松弛 (v, k')（标签记录连续 t_arr）
15   if u 是安全等待节点 and 等待段检查通过（x_u ∉ Ω^+(t), ∀t∈[t_k,t_{k+1}]）:
16     松弛 (u, k+1)，代价 Δt
17 return 无解
```

**第 12 步是核心**：对每条候选边检查其**完整的时空占用**，而不是只检查两个端点。
第 9 步的"复核失败"必须实现为可执行的修复策略（§7），不能只是检查标志。

## 6. 动态禁飞区更新：空间与时间同时变化

每次更新保留**版本号与生效时刻**：$\mathrm{NFZ}^{(r)}=\{\Omega_j^{(r)}(t),\mathcal{T}_j^{(r)}\}$。
新版本到达时：

1. 更新禁飞区的空间边界与有效时间；
2. 找出受影响的连接边（**空间索引查包围盒**：O(受影响边)，不全网重扫）；
3. 重新判定相关时空连接的可行性（epoch 标记、可逆：撤销即恢复）；
4. 执行中计划受影响 → **重规划剩余路径**（第一版全量重搜剩余段；局部修复列 §10）；
5. 对新生成的连续轨迹执行完整复核。

两个容易忽略的问题：

1. **已生成的路径不应自动视为仍然可行**——范围扩大或生效提前，原本可行的边会翻盘；
2. **更新到达时间与禁飞区生效时间必须同一时间基准**——时钟不统一，几何正确也会判错。

## 7. 连续轨迹平滑后的安全性验证（不能省）

Lin 等 (2021)：route（走廊）→ 三维 Dubins 平滑 path → 时间最优轨迹 trajectory。
**离散连接无冲突不自动保证平滑后无冲突**。最终可行性判据落在实际输出的时空轨迹
$\mathbf{p}(t)=(x(t),y(t),z(t))$ 上，检查其水平投影：

$$(x(t),y(t))\notin\Omega_j^{+}(t),\quad \forall t\in[t_0,T_{\mathrm{task}}],\ \forall j$$

四个检查点：

1. 平滑弧段是否穿越任何禁飞区（几何）；
2. 轨迹实际经过禁飞区附近的时间是否落入其有效时间窗（时间）；
3. 速度剖面变化导致的实际到达时间变化，是否使原可行连接翻盘
   （搜索的 $\tau_e$ 是估计，轨迹生成给出实际值）；
4. 不满足时回退搜索阶段重规划。

**修复阶梯**（可执行策略，逐级升级）：①偏移收缩重平滑（复用 Lin Fig.14 的偏差收缩机制，
触发条件从"几何不可实现"扩到"碰撞/禁飞冲突"）→ ②受影响段局部重搜 → ③全量时空重搜 →
④报不可行进闭环。

**时间一致性铁律**：时间不能只作为搜索节点的标签、之后被丢弃。最终轨迹的实际时间参数
必须与搜索阶段的时间估计一致；轨迹生成若改变了飞行时间，必须重检，必要时重搜。

## 8. 与上层的闭环衔接

- 禁飞区版本到达 / 复核失败 = **触发事件**（对应 `path_planning/README.md` §4.4.2
  "动态禁飞造成路径不可行"）；
- 反馈物：不可行的 $(i,j,k)$ 组合置 $\infty$ + 原因，可行组合回填真实飞行时间
  （$\lambda_{\mathrm{TPR}}=0$）——C(i,j,k) 按行/列**增量**回填（Lu 等 2026 Algorithm 2 语义），
  上层据此换巢 / 改派 / 推迟；
- **中途重规划起点** = 当前 (位置, 速度, 运动状态)：Lin 扩展网络的运动状态即接续状态
  （状态 0 悬停自然衔接等待边）。

## 9. 三个技术难点与对策

| 难点 | 风险 | 对策 |
|------|------|------|
| 时间离散误差 | 逐边取整累积 → 到达估计漂移 | 标签存连续时间；$\Delta t$ 灵敏度实验；以轨迹阶段实际时间为准并重检 |
| 整边时空相交判定 | 端点检查漏掉途中穿越 | $\mathbf{p}_e(\tau)$ 全程检查；边界变化按时段分段；安全膨胀 $d_s$ |
| 平滑后二次冲突 | 离散可行、连续违法 | §7 复核 + 修复阶梯；失败进闭环 |

## 10. 未来拓展（本阶段不做）

1. **TPR 风险场与综合代价**：本阶段 $\lambda_{\mathrm{TPR}}=0$（槽位保留），目标退化为纯时间；
   恢复后 $\mathrm{cost}=\lambda_t\cdot\mathrm{time}+\lambda_r\cdot\mathrm{TPR}$
   （骨架已在：`cost/composite.py`、`methods/tpr/`，口径见 `README.md` §4.3.2-4.3.3）；
2. **连续变化禁飞边界**（边界随 $t$ 移动 + 时空插值/运动规律）；
3. **增量修复**（D\* Lite / 局部修补替代全量重搜——Lin 在线已足够快，网络规模再上量级才需要）；
4. **高度层例外**（允许飞越的禁飞区：引入 $z$ 适用范围）；
5. **能耗等多目标**（Lin 结论中的开放方向）。

## 11. 复杂度

- 离线：仅多一层过滤 + 一次 union-find，构建复杂度不变；
- 在线：状态数 $|V_{\exp}|\times K$，松弛量 $|E_{\exp}|\times K$ 量级；NFZ 更新经空间索引局部化；
  A\* 进一步减扩展；
- 对照 Lin 原在线（重庆 1789 万边 ≈ 2s）：新增代价是时间维乘子 $K$ 与逐边时空检查；
  $K$（$\Delta t$）的选择是主要权衡，进 exp03。

## 13. 核心贡献表述（论文口径）

> 在控制网络路径规划框架中显式引入时间维度，将动态禁飞区建模为时空可行性约束，
> 使同一空间连接能够随出发时刻不同而具有不同的可用性，并通过连续轨迹复核
> 保证最终规划结果满足禁飞区约束。
