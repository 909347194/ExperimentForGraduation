# 硕士学位论文：多无人机智能调度中的任务分配与航迹规划方法研究

## 第4章 基于可见性图的城市无人机风险轨迹规划

针对复杂城市三维环境下无人机轨迹规划问题，本文采用**可见性图 / 稀疏路图（visibility graph）**方法。该方法离线将建筑外扩安全距离后简化，在简化轮廓、离散飞行高度层与网格骨干上采样节点，仅连接「视线可达且距离不太远」的节点对并做一次离线碰撞检测，再引入机动保护区剪枝高风险近距边，构建一张节点/边数可控、可长期复用的稀疏路图；在线阶段以堆优化 Dijkstra/A* 在三维欧氏代价下快速求解，动态禁飞区不在建图时处理，而在搜索每条边时按到达时刻的时间窗做可行性门（选项 A），因此几何图只建一次、可跨查询长期复用。相比基于状态机的控制网络，可见性图更轻、已通过独立碰撞审计验证（节点 1397、删边 65.2%、膨胀 10.35%±9.35%、ON/OFF 8/8 可达）。

本文在该方法基础上，引入静态永久禁飞区与动态临时禁飞区约束，并借鉴 Lu 等人分层事件触发闭环思想，面向多机巢动态滚动窗口场景做适配，构建上层任务分配与下层轨迹规划的双向闭环反馈。整体保留离线-在线两级架构：离线完成建筑简化、节点与边构建、静态约束处理；在线接收上层输出的起点-终点 OD，完成动态禁飞时间窗门控、图最短路搜索，输出折线路径，并（在后续收口工作中）增加平滑与时空轨迹生成。当出现动态禁飞阻断路径等事件时，下层将真实代价或不可行标记回传给上层任务分配层，触发任务重调度（更换机巢、重分配任务、推迟任务），实现分配-规划协同优化。

（注：第三方地面 TPR 风险建模在本章保留章节位置，但按 2026-10-30 裁定代码侧暂不实现，综合代价退化为纯飞行时间；详见 path_planning 模块地图 §2.3。）

---

复杂城市三维环境中，建筑物林立、空域管制严格，同时无人机飞行还需要兼顾地面人员财产安全，给无人机轨迹规划带来很大挑战。可见性图方法将复杂三维无限维轨迹优化问题拆解为离线稀疏路图构建与在线图搜索，在线计算开销很低，适合大规模城市场景。但该基线方法仍存在明显局限：第一，仅将建筑物作为障碍物，没有考虑城市禁飞区管制约束，未区分静态永久禁飞与动态临时禁飞；第二，只以飞行时间（几何代价）最小为优化目标，忽略无人机故障坠毁带来的第三方地面 TPR 风险；第三，该方法若输出仅为折线轨迹，无法直接反馈给上层任务分配，传统「先任务分配、后轨迹规划」的顺序模式，常采用欧氏距离预估飞行代价，会带来较大预估偏差，甚至出现分配完成但实际无可行飞行路径的问题。

针对上述不足，本章采用可见性图方法并开展改进，同时借鉴 Lu 等分层事件触发闭环的思想，面向本文多机巢动态滚动窗口任务分配场景，构建上层-下层双向闭环反馈机制。本章完整处理建筑障碍、静态 / 动态禁飞空域约束，并在章节层面保留第三方地面 TPR 风险建模位置，构造兼顾飞行效率与地面安全的综合代价函数（当前代码侧 TPR 权重置 0，退化为纯飞行时间）。

整个方法分为**离线预处理阶段**与**在线轨迹规划阶段**，并增加跨层闭环交互逻辑。

**离线预处理阶段不依赖具体飞行任务，只执行一次**：读取城市三维建筑数据，将建筑外扩安全距离后做几何简化（保留 STRtree 加速查询），在简化轮廓按大步长采样、叠加离散飞行高度层与网格骨干及关键点生成节点集合，剔除落在建筑或禁飞区内的落点；随后仅连接「视线可达且距离不太远」的节点对并做一次离线碰撞检测，再引入机动保护区按净空剪枝高风险近距边，得到可长期复用的稀疏路图与邻接表。

**在线规划阶段接收上层输出的 OD（起点-终点）任务以及动态临时禁飞信息，实时完成轨迹求解**：首先将端点吸附到视线可达的邻近节点并临时增边；随后在路图上以三维欧氏代价为目标执行堆优化 Dijkstra/A* 最短路径搜索，得到折线路径；动态临时禁飞不在建图时处理，而在搜索松弛每条边时，按该边被穿越的到达时刻窗（depart_time + 路长/巡航速度）做可行性门（选项 A），图只建一次、长期复用。后续收口工作将增加平滑（折线→光滑可飞曲线）与时空轨迹（补时间/速度）生成，并输出该条 OD 的总飞行时间与路径可行性标记。

在上下层闭环交互上，设置事件检测器识别触发事件：动态禁飞造成路径不可行、滚动窗口调度周期到达等。一旦事件触发，下层轨迹模块更新三维代价矩阵 C(i,j,k)：可行任务回填真实飞行时间代价，不可行的「无人机-任务-机巢」组合代价置无穷大，并回传给上层动态滚动任务分配模块。上层接收更新后的代价矩阵后执行重分配逻辑，优先更换任务执行机巢、将任务重新分配给其他无人机；若全部机巢均无可行路径，则推迟该任务执行。重分配产生新的 OD 集合，再次送入下层轨迹规划模块，由此实现任务分配与轨迹规划的事件触发式闭环。

本章分别开展单机消融实验、参数灵敏度分析、小规模闭环验证实验以及多机巢中规模联合仿真。单机算例验证改进方法对禁飞区的规避效果以及路径膨胀（相对直线）的可接受性；联合仿真将传统欧氏距离预估代价作为对照组，对比分析闭环机制对系统任务完成率、整体飞行代价的提升效果。

城市复杂三维环境中，无人机飞行不仅需要规避建筑物障碍，还需要遵守空域禁飞管制，同时需要降低无人机故障坠毁带来的地面第三方安全风险。本文第 3 章完成了多机巢动态滚动窗口任务分配研究，但传统任务分配大多采用欧氏距离估算飞行代价，忽略城市真实障碍物、禁飞约束与地面风险，容易出现代价预估偏差大、分配后不存在可行轨迹等问题。

可见性图方法将复杂三维轨迹优化分解为离线稀疏路图构建与在线图搜索，在线计算开销小，适合大规模城市场景。但该基线仅考虑建筑物障碍物，缺少禁飞空域约束，未考虑第三方地面 TPR 风险，且离线图需配套在线搜索与闭环反馈才能对接上层任务分配模块。

针对上述问题，本章开展**城市无人机风险轨迹规划**研究。本文所指风险包含两层含义：一是无人机自身飞行安全风险，即建筑、禁飞区带来的碰撞风险；二是无人机坠毁对地面人员、财产造成的第三方 TPR 风险。本章以可见性图方法为基线进行改进，引入静态永久禁飞、动态临时禁飞约束，在章节层面保留时变第三方地面 TPR 风险场建模位置，建立飞行时间-地面风险加权综合代价函数（当前实现 TPR 权重置 0），并（在后续收口工作中）增加平滑后轨迹的碰撞校验，避免平滑轨迹侵入禁飞区与建筑物。在此基础上，借鉴分层事件触发闭环思想，面向本文多机巢动态滚动任务分配场景，构建上层任务分配与下层轨迹规划双向闭环反馈机制。当出现动态禁飞阻断路径等事件时，下层将真实代价或不可行状态回传给上层，触发任务重调度，实现分配与轨迹规划协同优化。

## 方法说明：可见性图（experiments/exp02_vg 验证，第 4 章正文方法）

`methods/visibility_graph/` 是本文第 4 章采用的轨迹规划方法（**非替代方案**），由「建筑简化 + 轮廓采样节点 + 视线可达边 + 机动保护区」设想验证而来；`control_network_planning/` 已于 2026-10-30 裁定弃用/存档，仅作方法对比参考。

- 建筑外扩安全距离后简化，STRtree 加速候选筛选；节点在简化轮廓按大步长采样 + 离散高度层 + 网格骨干；
- 边只连「视线可达且距离不太远」的节点对，离线一次碰撞检测；机动保护区删高风险近距边
  （实测删边 57–66%，与文献量级一致）；
- 堆优化 Dijkstra/A*（自实现邻接表，不引入 NetworkX）；
- **放弃 TPR**，仅用几何约束（建筑 + 禁飞区）；动态禁飞按**选项 A** 在 A* 查询期按时间窗检查，图只建一次、长期复用；
- 验证报告、分区 profiling 与文献可比口径见
  [`experiments/exp02_vg/results/VALIDATION_REPORT.md`](experiments/exp02_vg/results/VALIDATION_REPORT.md)
  与 `experiments/exp02_vg/README.md`。

> 第三方地面 TPR 风险在章节层面保留建模位置，但按 2026-10-30 裁定代码侧暂不实现，综合代价当前退化为纯飞行时间。平滑（smoothing.py）与 `interface/PathPlanner` 闭环门面**均已基于可见性图实现**；**时间最优轨迹（time-optimal trajectory）不在本研究范围内**，由下游 UAV 飞行控制器完成——本方法定位为**路径规划器（path planner）**，交付物是几何可行路径（path）。
