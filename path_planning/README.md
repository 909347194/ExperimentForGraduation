# 硕士学位论文：多无人机智能调度中的任务分配与航迹规划方法研究

## 第4章 基于改进控制网络的城市无人机风险轨迹规划

针对复杂城市三维环境下无人机轨迹规划问题，本文以 Lin 等人提出的两阶段控制网络框架为基线。该方法依靠离线预构建控制网络、在线快速寻路，具备计算速度快的优势，但仅考虑建筑物物理障碍，缺少空域禁飞约束，未考虑无人机坠毁带来的地面第三方 TPR 风险，且为单机独立规划，无法直接对接多机巢动态滚动任务分配系统。

本文在基线框架基础上，引入静态永久禁飞区与动态临时禁飞区约束，构建第三方地面 TPR 风险代价模型，建立**飞行时间‑地面风险加权综合目标函数**；借鉴 Lu 等人分层事件触发闭环的思想，面向多机巢动态滚动窗口场景做适配改造，构建上层任务分配与下层轨迹规划的双向闭环反馈。 整体保留离线‑在线两级架构：离线完成控制点布设、网络构建、静态约束处理、链路飞行时间与 TPR 风险预计算；在线接收上层输出的起点‑终点 OD，完成动态禁飞链路剪枝、网络最短路径搜索、三维 Dubins 曲线平滑，并增加平滑后轨迹二次碰撞校验，再生成时间最优时空轨迹。 当出现动态禁飞阻断路径、轨迹 TPR 风险超阈值等事件时，下层将真实代价或不可行标记回传给上层任务分配层，触发任务重调度（更换机巢、重分配任务、推迟任务），实现分配‑规划协同优化。

---

复杂城市三维环境中，建筑物林立、空域管制严格，同时无人机飞行还需要兼顾地面人员财产安全，给无人机轨迹规划带来很大挑战。Lin 等提出的**控制网络两阶段轨迹规划方法**，将复杂三维无限维轨迹优化问题拆解为离线网络构建与在线规划，在线计算开销很低，适合大规模城市场景。但该基线方法仍存在明显局限：第一，仅将建筑物作为障碍物，没有考虑城市禁飞区管制约束，未区分静态永久禁飞与动态临时禁飞；第二，只以飞行时间最小为优化目标，忽略无人机故障坠毁带来的第三方地面 TPR 风险；第三，该方法属于单机孤立轨迹规划，输出的轨迹结果无法反馈给上层任务分配，传统 “先任务分配、后轨迹规划” 的顺序模式，常采用欧氏距离预估飞行代价，会带来较大预估偏差，甚至出现分配完成但实际无可行飞行路径的问题。

针对上述不足，本章基于该两阶段控制网络基线框架开展改进，同时借鉴 Lu 等分层事件触发闭环的思想，面向本文多机巢动态滚动窗口任务分配场景，构建上层‑下层双向闭环反馈机制。本章完整处理建筑障碍、静态 / 动态禁飞空域约束，引入第三方地面 TPR 风险，构造兼顾飞行效率与地面安全的综合代价函数。

整个方法分为**离线预处理阶段**与**在线轨迹规划阶段**，并增加跨层闭环交互逻辑。

**离线预处理阶段不依赖具体飞行任务，只执行一次**：读取城市三维建筑数据，在建筑周边布设控制点；针对静态永久禁飞区，控制点设置在禁飞安全缓冲之外，链路碰撞检测时直接删除穿过建筑或静态禁飞区域的链路，完成原始控制网络构建；进一步构建扩展虚拟控制网络，使用 7 类虚拟节点表征无人机不同运动状态，依据无人机动力学模型预计算每条虚拟链路的最小飞行时间；同时基于城市人口密度数据预计算每条链路的 TPR 第三方风险代价，支持白天、夜间两套时变 TPR 风险场，将完整扩展控制网络保存至本地文件，避免重复计算。

**在线规划阶段接收上层输出的 OD（起点‑终点）任务以及动态临时禁飞信息，实时完成轨迹求解**：首先对动态临时禁飞做在线链路临时剪枝，并开展连通性校验；随后在扩展控制网络中以综合代价（飞行时间与 TPR 风险加权）为目标执行 Dijkstra 最短路径搜索，得到网络上的折线路径 route；再采用三维 Dubins 曲线算法做路径平滑得到空间几何 path。为解决平滑圆弧可能超出走廊范围侵入禁飞区或建筑的问题，本文增加后置三维碰撞校验机制，若平滑轨迹发生冲突则调整偏移距离对路径进行修正；最后运行时间最优轨迹生成算法，输出包含位置、速度、加速度信息的完整时空轨迹 trajectory，同时输出该条 OD 的总飞行时间、总 TPR 风险以及路径可行性标记。

在上下层闭环交互上，设置事件检测器识别三类触发事件：动态禁飞造成路径不可行、生成轨迹 TPR 风险超出预设安全阈值、滚动窗口调度周期到达。一旦事件触发，下层轨迹模块更新三维代价矩阵\\(C(i,j,k)\\)：可行任务回填综合代价，不可行的「无人机‑任务‑机巢」组合代价置无穷大，并回传给上层动态滚动任务分配模块。上层接收更新后的代价矩阵后执行重分配逻辑，优先更换任务执行机巢、将任务重新分配给其他无人机；若全部机巢均无可行路径，则推迟该任务执行。重分配产生新的 OD 集合，再次送入下层轨迹规划模块，由此实现任务分配与轨迹规划的事件触发式闭环。

本章分别开展单机消融实验、参数灵敏度分析、小规模闭环验证实验以及多机巢中规模联合仿真。单机算例验证改进方法对禁飞区的规避效果以及飞行时间‑TPR 风险的多目标权衡；联合仿真将传统欧氏距离预估代价作为对照组，对比分析闭环机制对系统任务完成率、整体飞行代价、第三方总风险的提升效果。

---

城市复杂三维环境中，无人机飞行不仅需要规避建筑物障碍，还需要遵守空域禁飞管制，同时需要降低无人机故障坠毁带来的地面第三方安全风险。本文第 3 章完成了多机巢动态滚动窗口任务分配研究，但传统任务分配大多采用欧氏距离估算飞行代价，忽略城市真实障碍物、禁飞约束与地面风险，容易出现代价预估偏差大、分配后不存在可行轨迹等问题。

Lin 等人提出的两阶段控制网络轨迹规划框架，将复杂三维轨迹优化分解为离线网络构建与在线寻路，在线计算开销小，适合大规模城市场景。但该基线仅考虑建筑物障碍物，缺少禁飞空域约束，未考虑第三方地面 TPR 风险，且为单机孤立规划，无法直接和上层任务分配模块交互。

针对上述问题，本章开展**城市无人机风险轨迹规划**研究。本文所指风险包含两层含义：一是无人机自身飞行安全风险，即建筑、禁飞区带来的碰撞风险；二是无人机坠毁对地面人员、财产造成的第三方 TPR 风险。本章以控制网络为基线进行改进，引入静态永久禁飞、动态临时禁飞约束，构建时变第三方地面 TPR 风险场，建立飞行时间‑地面风险加权综合代价函数，并增加 Dubins 曲线平滑后的二次碰撞校验，避免平滑轨迹侵入禁飞区与建筑物。在此基础上，借鉴分层事件触发闭环思想，面向本文多机巢动态滚动任务分配场景，构建上层任务分配与下层轨迹规划双向闭环反馈机制。当出现动态禁飞阻断路径、轨迹 TPR 风险超出安全阈值等事件时，下层将真实代价或不可行状态回传给上层，触发任务重调度，实现分配与轨迹规划协同优化。
