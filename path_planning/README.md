# 硕士学位论文：多无人机智能调度中的任务分配与航迹规划方法研究

# 研究思路

本研究面向滚动式多无人机任务调度中的动态空域冲突问题，在上层任务分配结果给定的条件下，研究兼顾本轮无人机群内部协同避碰与既有执行航迹避让的连续时空航迹规划方法。

首先，根据无人机任务访问顺序和城市空间约束生成初始空间路径，并进一步构建满足运动学约束的连续时间参数化轨迹。其次，将上一轮尚未完成任务的无人机正在执行的未来航迹作为固定时空约束，建立同时涵盖本轮无人机之间以及本轮无人机与既有执行无人机之间的安全间隔约束。随后，通过连续轨迹冲突检测识别潜在危险交会，并以冲突驱动的局部协调机制为核心，在保持既有航迹不变的条件下，综合调整本轮无人机的出发时间、局部速度及必要的空间路径，降低冲突消解所需的延误与绕行代价。最后，通过全局冲突复检、运动可行性验证和滚动状态更新，形成兼顾飞行安全、任务效率和动态执行一致性的多无人机连续时空航迹规划方法。

**当前最值得深入研究的核心不是再增加一种路径搜索算法，而是建立“既有航迹约束下的新航迹连续时空协调机制**

**基于既有航迹约束的多无人机冲突检测与空间重规划方法。**

- 空间路径：继续使用可见图生成初始航迹。
- 既有航迹：作为带有运动时间信息的动态避让对象。
- 时间：根据预设速度计算，用于识别真实的时空冲突，不参与联合优化。
- 冲突消解：优先局部空间绕行，重新检查新—新与新—旧航迹。
- 运动约束：对最终轨迹进行速度、加速度、转弯及安全间隔验证。

这是一条更适合当前研究阶段的路线。需要注意的是，既然你采用了固定时间安排，就应当在论文中明确这是一个**固定速度参数化下的时空冲突检测与空间重规划方法**，而不是声称完成了连续时空联合优化。
