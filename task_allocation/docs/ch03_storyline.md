## 1. 一句话主张与章定位

> **一句话主张**：当任务分配从"固定清单、单基地、平面图"走向"持续到达、多机巢、高原三维地形"，联合优化（归属 + 顺序 + 终点 + 选择）强耦合且 NP-hard；本章按**可精确性**将其分层——外层进化只搜它擅长的（归属与顺序），内层最小费用流精确解它擅长的（终点机巢），评估端做选择性裁量，滚动层管时间维度。

**章定位三件套**：
- **外衣（问题整合）**：四维扩展的问题定义——对应文献空白 G1（本轮检索范围内无同时满足四维的工作）；
- **主干（可分解性）**：按可精确性分层——这是全章真正的学术内核，也是不需要"优于谁"的实验也能立住的部分；
- **节段（算法改进）**：DMDE 的结构扩展下沉为"外层求解器"的实现细节，每项对应一个"不这样会怎样"。

**为什么是这个组合**：当前证据状态下（无 baseline、终点进编码消融不可引用、exp02 有反证），唯一同时满足「学术辨识度」与「证据诚实」的讲法。主张**结构性质**（条件最优、不变式、接口干净），不主张性能优越性。

## 2. 诊断：现有组织方式的三个病症

| 病症 | 现状 | 后果 |
|---|---|---|
| 清单式问题特征 | §1 五条特征平铺（动态到达/状态变化/多巢起降/数量不匹配/价值与代价并存） | 读不出"为什么难"，每节像系统说明书 |

## 3. 核心设备一：四对张力表（§2 问题特征的重写依据）

> 不讲"五个平行特征"，讲"四对张力"：每对 = 一个失效的经典假设 + 一个本章设计决策。问题定义、模型、算法各节全部回引此表。

| # | 张力 | 失效的经典假设 | 本章的设计决策 | 回引节 |
|---|---|---|---|---|
| T1 | **规模** | 任务集合固定、全部必须执行 | 选择性 `y_j=0` + 阶段一筛选；上界按**机队吞吐**标定 | §4、§5、§6.3 |
| T2 | **耦合** | 单基地往返、终点固定 | 终点机巢 `z_ub` 为决策变量 → **分层**：外层搜路线、内层 MCF 精确定点 | §5、§6.2 |
| T3 | **近似** | 欧氏距离代价 | DEM 垂直切面三维代价 `C_ij^3D` 进 cost matrix（与 WAFC-RRAS 同源，须注明差异） | §6.5 |
| T4 | **时间** | 一次性静态规划 | 滚动时域 + 事件触发重规划 | §7 |

**张力表的第二个用途**：它是全章的"回引骨架"——后面每一节开头都用一句话回引对应的张力编号（"为解决 T2 的耦合……"），章节之间就从并列变成因果。

## 4. 核心设备二：求解器内部的三个"为什么"（§6 的重写依据）

> §5 的六项改进从并列改为从属：编码/修复/回写三项各自回答一个"怎么办"，终点分层/选择性/三维代价回引张力表。

| 审稿人会问 | 本章的回答 | 落点 |
|---|---|---|
| 离散结构（归属/顺序）怎么进连续 DE？ | 统一两层编码：基因三元组 + **固定布局**代价值向量，二者解耦；差分有"航程差"的物理意义 | §6.1 |
| 变异/交叉后的临时解怎么保可行？ | 逆映射三规则 + 温度自适应 softmax + swap/insert/reverse；无效值修补 | §6.1 |
| 修复/裁剪后的成果怎么不丢？ | 修复不动点 `prune → repair_range → choose_end_nests` + Lamarckian 只回写起始基因、绝不增删基因（长度恒 `N` 不变式） | §6.4 |
| 终点巢为什么不在编码里？ | 给定路线后它是**线性可精确解**的（小规模运输问题 → MCF）；编进基因只会增大搜索空间、且与访问顺序强耦合 | §6.2 |
| `y_j=0` 为什么不在编码里？ | 见 §7.1 诚实点一 | §6.3 |

## 5. 逐节故事线（Hook / 必含 / 禁说）

> Hook = 该节第一句话（或第一段）的写法；必含 = 不可缺席的要素；禁说 = 当前证据下不能出现的断言。

### §1 章引言
- **Hook**：「当一支无人机机队从"单基地、固定任务清单、平面地图"走向"多机巢、任务持续到达、高原三维地形"，任务分配问题的每一个经典假设都需要被重新审视。本章要回答的不是"如何更快地分配一批固定任务"，而是"**哪些任务值得做、由谁做、按什么顺序、降落在哪个巢**"。」
- **必含**：产业现状一句（多机巢集群巡检落地案例）；本章边界声明（任务级分配 + 三维代价近似，禁飞区/动力学/风险场属第 4 章）；本章结构一句。
- **禁说**：任何"优于现有方法"的总括句。

### §2 问题特征与核心挑战
- **Hook**：「四个经典假设在巡检现实中**同时**失效——这是本章问题定义的来源，而非背景罗列。」
- **必含**：四对张力表（§3）；每对张力配 1–2 句真实场景事实（高原高差、任务积压、机巢泊位有限）；显式声明"四对张力的**组合**正是文献断点"（回引 positioning G1）。
- **禁说**：把五个旧特征平铺保留；无依据地说"现有研究均未考虑"（只能说"本轮检索范围内未发现同时满足四维的工作，尚待系统文献检索确认"）。

### §3 总体求解框架
- **Hook**：「分层不按功能分，按**可精确性**分。」
- **必含**：三层结构图（外层进化 / 内层精确 / 评估端裁量 + 滚动层）；为什么分层的论证（联合优化强耦合 NP-hard；终点巢给定路线后线性可解；选择性给定路线后可判定）；与"聚类 + 每机独立优化"工程范式（CN117993672A 等）的差异一句。
- **禁说**：「分层不损失最优性」的全称断言——只能是「终点巢在给定路线下条件最优」。

### §4 第一阶段：动态任务选择机制
- **Hook**：「选择层不是可选预处理，而是把 NP-hard 联合问题的规模压回可解域的手段——但压缩上界必须按**机队吞吐**标定，按机数标定会伤质量（本章实验给出的教训，直接写进设计动机）。」
- **必含**：五因素优先级 `P_i(t)`；候选池 `n_cand = ⌈α·K⌉`（与 cap(t) 解耦、能力无关，仅受计算预算/任务总数约束）；选择数 `n_sel = min(⌈max_ratio·K⌉, cap(t))`（cap 才是能力卡口）；边际增益 `Δ_i = ΔB_i/ΔC_i`（`ΔC` 用 3D 插入式估计 `C_ai+C_ib−C_ab`，回引 T3）；可行性 prefilter/postcheck；**吞吐标定的动机段**（exp02：8 机场景分层 F1≈130~146 vs 全量 314，根因是 α 按机数线性标定）。
- **禁说**：「压缩不伤质量」「筛选后解质量接近全量」——在 α 改按吞吐标定并补"分层 vs 全量目标差距列"之前，这两个说法禁止出现；此节只能讲"规模压缩机制 + 标定口径"。

### §5 第二阶段：选择性多机巢 MUAS 模型
- **Hook**：「四类决策变量逐一回应四对张力：`y_j` 回应 T1，`x_uj` 与 `π_u` 是经典 MUAS 决策，`z_ub` 回应 T2，三维代价口径回应 T3。」
- **必含**：问题定义（选择性、异源起降、三维代价、滚动接口）；双目标 `max F1 = ΣR_j·y_j` / `min F2 = C_3D + 惩罚`；可选瓶颈机时间项 `F3 = max_k T_k`；11 约束开关的**动机表**（每个约束对应哪个真实业务约束，而非罗列开关名）。
- **禁说**：「全局联合最优模型」——模型是完整的，但求解是分层的，须写明"模型完整 / 求解分层"的区分。

### §6 改进离散映射差分进化算法
- **Hook**：「外层进化只做它擅长的部分：UAV 归属与访问顺序。它的每一项结构扩展，都对应一个"不这样会怎样"。」
- **必含**（按 6.1–6.5 顺序，每节回引张力/为什么）：
  - 6.1 统一编码：哨兵基因两类角色表（`≥0`/`-1`）、固定布局两段、`(K+N, N)` 代价矩阵、恒走 SRP（`K ≤ N-1`，balanced/overloaded 不可达——**写进正文**，这是编码契约的核心）、逆映射四阶段；
  - 6.2 终点分层：内层 MCF（源→航次→机巢→汇，自实现 Bellman-Ford 无 scipy）、末态泊位口径、**完整成本评价原则**（返航代价进 F2，否则"先优化路线最后随便收尾"）、条件最优声明、方案 B 一段带过（推迟 pro 分支，不宣称）；
  - 6.3 选择性解码端：判据 `λ·saving > R_eff·(1+margin)`、`U_t^exec ⊆ U_t^avail` 两条通道（`y_j=0` 与 `n_u=0` 决策位置不同，须分别说明）；
  - 6.4 约束处理：修复优先罚则兜底、不动点收敛的耦合论证（三者互相牵引）、Lamarckian 双通道回写；
  - 6.5 三维代价：`C_ij^3D` 预计算嵌入、与第 4 章航迹规划的接口一句；
  - 6.6 算子对照：与母本公式逐条对应表 + F/GMR 两处偏差修正的说明。
- **禁说**：「终点进编码更优（−2.4%）」——方案 B 默认关闭、数据不引用为主线证据；「优于 Zhao Ming 2017 及其他算法」——无 baseline；「收敛速度提升 x%」——无对照实验数据。

### §7 动态滚动与闭环运行
- **Hook**：「时间维度选滚动时域 + 事件触发，而非 MDP/RL——换可解释、可复现、与精确子求解的干净接口。」
- **必含**：`T_{t+1} = remain ∪ new ∪ release` 状态转移；UAV 状态机与事件触发（故障/紧急任务/机巢不可用）；九步单周期编排；每周期集合关系有测试守护一句（工程可信度）。
- **禁说**：「实时性达到 xx 毫秒」——除非有实测数据；「闭环稳定」的定量说法——当前只有 5 seed 可复现，够写"可复现"，不够写"稳定"。

### §8 本章研究内容与贡献定位
- **Hook**：「本章的贡献按**可主张程度**分三档陈述。」
- **必含**：主张分级表（见 §6 本文档）；三个贡献点按分级重写——
  1. 问题定义层：四维整合（强主张）；
  2. 模型/方法层：分层结构 + 条件最优 + 不变式 + 算子保真（强主张，结构性）；Lamarckian 应力消融（条件主张）；
  3. 框架/数据层：真实 DEM + 8 机巢滚动闭环（强主张）；
  4. 局限与未来工作：无外部基线、约束活性、吞吐标定、方案 B 推迟（主动写）。
- **禁说**：「提升任务完成质量与资源利用效率」这类无对照的性能总括——替换为结构性表述。

## 7. 三个诚实点的标准写法（主动写 = 成熟；被问 = 硬伤）

### 7.1 选择性为什么在解码端（§6.3 必写段）

> 标准措辞方向：「本章将 `y_j=0` 置于解码后的代价—收益判别，而非进化编码，这是一个**有代价的设计选择**：搜索空间不为选择性服务，所得解是给定路线下的条件最优。选择它的理由有三：① SRP 不变式要求基因总数恒定、每任务必出现，删除基因会破坏 DE 代价矩阵对齐；② `y_j` 的最优取值基本由代价结构（`λ·saving` 与 `R_eff` 的相对关系）决定，占用 `N` 维搜索维度增益有限；③ 解码端判别使选择性判据与航程修复、终点分配共用同一三维代价口径，可纳入同一不动点迭代。代价是结论的条件最优性，本章明确承认。」

### 7.2 exp02 反证怎么处理（§4 动机段 + §8 局限）

> 标准措辞方向：「任务选择层的压缩上界若按**机数**线性标定（`n_cand=⌈α·K⌉`），在任务远多于机数的场景下与机队实际吞吐能力不匹配——本章实验（8 机、任务数 ≫ 机数）显示该标定下分层解收益约为全量直接求解的 42%。因此本章将选择层定位为**按机队吞吐标定的规模控制机制**，而非无损压缩；吞吐标定口径的修正与"分层 vs 全量"目标差距列详见实验章。」

### 7.3 与第 4 章的边界（§1 必写段）

> 标准措辞方向：「本章产出为**任务级分配方案与三维代价近似**：起降点间的航程以 DEM 垂直切面代价计入，但禁飞区、动力学约束、风险场与精细航迹属第 4 章内容。任务分配与航迹规划之间以"代价矩阵 + 可达性判据"接口，避免将三维航迹搜索与高维组合优化直接耦合。」
