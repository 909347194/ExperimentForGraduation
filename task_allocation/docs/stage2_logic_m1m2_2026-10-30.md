# 第二阶段方法逻辑重析（M1 + M2 落位后）

> 2026-10-30。前提：M1（搜索期精英 polish + 档案）与 M2（双通道拉马克回写）
> 均已实现（M2 边界见 `m2_gene_writeback_design_2026-10-30.md`）。
> 本文重推第二阶段（选择性多机巢 MUAS）的方法逻辑——不是罗列组件，
> 而是回答"这是一个什么算法、每层为什么存在"。

## 0. 一句话定位

**第二阶段 = 构造式解码器 + 拉马克式 memetic DE。**

进化管**组合**（谁做、什么顺序），构造管**可行**（修成能交付的解），
精修管**成本**（在表型上下山），回写让四者**互相成就**（精修的果实
进入基因池，进化围绕果实继续探索）。

## 1. 六层逻辑结构

| 层 | 载体 | 职责 | 对应组件 |
|----|------|------|----------|
| **表达层** | cost_vector（[K,N) 成本指纹布局） | 基因型空间；DE 差分的真正作用域 | `encoder` / `inverse_phi`（反映射） |
| **构造层** | repair(decode(g)) = 表型 | 任意解码结果 → 可行交付解；"完成是约束"的**构造性实现** | `build_solution` 修复链（覆盖装载→时序归位→航程闸→终点巢 min-cost flow→覆盖门禁） |
| **评价层** | 分层适应度 f | 覆盖门禁口径：硬违约 T0 / 覆盖 skip / 迟到 / λ·成本 | `problem.evaluate` + 快照权重 |
| **精修层（M1）** | 表型邻域下降 | 收割"适应度看不见"的成本/迟到改进；档案跟踪 | 精英 polish（relocate/swap/position）+ 交付后 cost_polish 算子组 |
| **遗传层（M2）** | 双通道回写 | 精修表型写回基因（起始+巡游通道），解码一致性闭合 gene≈phenotype | `lamarckian_reencode`（扩展） |
| **多样性层** | 灭绝 + 护栏 | GMR=1−CR 灾变重启；写回护栏（源过滤/表型复核/范围控制） | `extinction` + 回写纪律 |

## 2. 逻辑主线

```text
DE 差分（cost 指纹空间）
  → 反映射 φ'（归属 + 顺序，带温度）
  → 修复链构造（把"可能烂"的解修成"可行交付"解）
  → 分层适应度评价
  → 贪婪选择（赢家）
  → M1：赢家精修（邻域下山）→ 档案
  → M2：精修表型写回赢家基因（双通道 + 解码校验 + 不变式断言）
  → 下一代差分围绕"精修后的子空间"继续
  →（收敛后）交付 polish + 终点巢重解 + 采纳闸
```

**角色变化（与 M1/M2 之前对照）**：

| 组件 | 之前 | 现在 |
|------|------|------|
| DE | 独立求解器，直接对解爬山 | **组合调度器**：为构造+精修提供多样化的起点，重组"构建块"（成本指纹=离散对锚点） |
| 修复链 | 善后修补 | **解码语义的一部分**：表型 = repair(decode(g))，构造性保证可行 |
| polish | 交付后收尾 | 三处复用同一套邻域算子：搜索期下降算子（M1）/ 基因改良来源（M2）/ 交付收尾 |
| 收敛曲线 | DE best = 唯一判读 | 双曲线：DE best（组合搜索）+ 档案 best（精修下山）分开画、分开解读 |

## 3. 失效模式 → 机制映射（诊断驱动设计，论文叙事核心）

每个机制都对应一个**被实测出**的失效模式——方法逻辑的说服力在这里：

| 实测失效模式 | 证据 | 机制 |
|--------------|------|------|
| 解不可行/幽灵覆盖 | "纸面可行执行弹回"、E1E2 门禁恒真完成率 −5pp | 覆盖门禁 + 构造式修复链（完成是约束） |
| ETA 与代价两套长度 | 统一前 ETA 系统性低估、放进来不及的任务 | 统一三维航程口径（`arrival_times` 单源） |
| 收敛曲线第 3 代躺平 | T9：梯度比 1e-5 + 基因型坍缩 | M1 精修（显式邻域收割成本） |
| 归属逐代复现、顺序失能 | T9：SRP 锁归属 + 只回写起始基因 | M2 双通道回写（顺序重获可遗传性） |
| polish 引入硬违约/拆链 | 2026-10-30 交叉审查 | polish 时序门 + 链成员禁迁 |
| 早熟 | 收敛曲线 | GMR 灭绝（1−CR）+ 写回护栏 |

**叙事口径**：本方法不是机制堆叠，而是**诊断→机制**的闭环——每一层
的存在理由都是一次实验暴露的失效模式。

## 4. M1 + M2 后的预期行为

1. **曲线解读变化**：DE best 曲线仍会早平（差分腿本来就弱），但档案曲线
   持续下降（seed42 实证：周期 2 档案 −32.6%、第 40 代仍降）。交付解 =
   max(收敛后 polish, 档案) 的更优者——**M1 收割、M2 让种群跟随**，
   两者合力才可能超过 post-hoc polish 的追平上限（A/B 已证单独 M1 会被追平）。
2. **复杂度**：每 K 代一次精英 polish（预算 memetic_max_evals）；
   写回 O(N) + 一次 temperature=0 解码校验。整体单周期开销 +3% 量级
   （seed42 实测 212s→214.5s）。
3. **确定性保持**：写回是确定性的（校验用无扰动解码）；回调异常吞并
   停用 + stderr 警告（不静默）。A/B 可逐位复现。
4. **收敛判据变化**：DE 早平不再等于"搜索结束"；应以"档案 + DE 双曲线
   均平"为收敛判据（或沿用现有 stop_when_stable 的周期级判据）。

## 5. 边界外（本逻辑不解决）

- **跨机时序口径**：constraints 只判同航次内；polish 对链成员保守禁迁
  ——跨机顺序比对落地前，链拆分仍是盲区；
- **DE 对顺序的原生探索仍弱**：差分作用在 cost 指纹空间，顺序主要由
  精修+写回推动。若 M2 后仍不足，下一档是"顺序专用变异算子"（对巡游段
  做 swap/insert/reverse 的定向扰动）；
- **指纹歧义**：不同 (uav,task)/(task,task) 对的 cost 相近时，反映射表达
  漂移——M2 解码校验是防线，但大规模下需监控；
- **λ 量纲 / 时间窗标定**：口径问题不因搜索机制改变。

## 6. 验证计划

三臂 A/B（3 seed）：A 基线 / B M1 / C M1+M2。指标：

1. 交付路径成本、迟到量、完成率（主指标）；
2. **双收敛曲线**：DE best vs 档案 best（M1/M2 的独立贡献可见）；
3. **种群多样性**：cost_vector 代际方差（M2 同质化护栏的转正门槛）；
4. 墙钟（精修/写回开销）。

转正判据：C 交付成本显著优于 B（配对 t 检验），且方差不加速坍缩。
