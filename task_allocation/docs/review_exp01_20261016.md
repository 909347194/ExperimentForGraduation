### 统计协议层（当前 results 尤其严重）

- **当前入库结果是单 seed 调试跑**（`seeds: [42]`，`solver.max_iter: 100`），
  `seed_summary` 为空、无 σ、无分布——**不构成任何统计证据**。正式实验必须多 seed。
- 5 seed（启用时）对随机元启发式偏少；`std(ddof=0)` 低估样本离散（建议 ddof=1）；
  **无显著性检验**（配置对照应做配对 Wilcoxon signed-rank + 效应量，seed 配对复用）；
  无置信区间。
- 11 张图中 8 张只画代表 seed（PIPELINE 已知）——出图须标注，避免 cherry-picking 观感。

## 4. 方法正确性审计结论（exp01 定位：方法正确性验证）

工具：`exp01_smoke/audit_correctness.py`（20 项不变量，从落盘结果独立复核；
可重复运行作回归门禁）。本跑结果：**19 PASS + 1 WARN，方法闭环与理论口径一致 ✔**。

| 不变量组 | 结果 | 关键证据 |
|---|---|---|
| A 终局守恒 | ✅ | 60 = 60+0+0+0；summary 与任务表互验一致 |
| B 完成唯一 | ✅ | 跨周期无重复计；每周期计数自洽 |
| C 完成闸门 | ✅ | 物理不可行 ∩ 完成 = ∅；迟到 ⊆ 完成（迟到≠废飞） |
| D 时间语义 | ✅* | 迟到 = 仿真 ETA−latest（非周期末记账时刻）；*残差见 F2 |
| E 奖励守恒 | ✅ | Σf1 = 交付端折减奖励，相对差 **0.0000%** |
| F 池守恒 | ✅ | 水位恒等式 + 逐周期递推均闭合 |
| G 选择漏斗 | ✅ | 逐级单调 + n_selected ≤ αK |
| H 参与机数 | ✅ | K ≤ min(K_avail, 任务数)（SRP 不变式） |
| I 收敛单调 | ✅ | DMDE best fitness 非增 |
| J 航程物理 | ✅ | 逐腿有序 estimate 独立重算与 est_cost **逐米吻合**；全航次 ≤ 80km |
| K 无瞬移 | ✅ | 下周期起点 = 上周期终点机巢 |
| L 容量/机巢 | ✅ | 占用 ≤ 4；终点机巢 id 合法 |
| M 段长口径 | ⚠️ WARN | 见 F1 |

### 发现 F1（WARN，低危）：段长口径的方向性分裂

`make_distance_fn` 的记忆化把 (A,B)/(B,A) 当对称存取，但**地形跟随航程方向相关**
（爬升规则从起点扫描，`_generate_flight_path` 非对称）→ **ETA/时间模型（对称缓存）
与代价矩阵（有序 estimate）段长可差 0.1~0.8%**（本跑 2 段：38791.0 vs 39117.8、
19310.1 vs 19219.4）。有序口径与物理一致（J 逐米吻合）。建议：memo 改按有序键存取
（内存×2）或在论文/文档明确声明对称近似及误差界。

### 发现 F2（开放，低危）：lateness 记录与交付航次 ETA 重算有 ≤18s 残差

用落盘数据独立重算交付航次的 ETA，与记录的 lateness（→奖励折减 L 的唯一来源）
存在 −17.5 ~ +15.2s 的残差（方向混合）。已逐一排除：任务集、访问顺序（120 全排列搜索）、
段长双口径（有序/对称）、出发基准、服务时间、任务窗口；插桩运行（抓
`check_time_window_constraint` 7776 次调用）进一步确认：同进程内逐腿段长与任务窗口
逐项一致，但最终迟到值仍差 1~18s，机制待定位（嫌疑：搜索期缓存/中间解与最终解的
评价错位）。影响：迟到秒数误差 ≤2%、奖励折减 ≤0.5%、**不影响可行性判定与完成协议**；
奖励链自洽（E 项 0.0000%）。修复建议：在交付时刻用最终航次重算 lateness
（horizon `_advance_execution` 内补一次 ETA 仿真，不再透传评价端 meta）。

### 总结

exp01 作为**方法正确性验证**实验达成目的：闭环全部结构不变量成立，物理可行性经
独立重算确认，奖励/完成/池记账三方互验闭合。两个 WARN 均为低危口径精修项，
不影响“方法理论上正确”的结论。
