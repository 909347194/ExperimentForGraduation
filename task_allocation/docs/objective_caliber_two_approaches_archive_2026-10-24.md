# 目标口径：两种实现方法存档案（非门禁 big-M ↔ 覆盖门禁）

> 存档性质：本文件记录「完成是约束、成本是目标」这一最高裁定下，**两套实现口径**
> 的来龙去脉、数学形式、取舍与最终裁定。2026-10-24 起 **门禁（coverage_gate）成为
> 唯一主口径，代码只保留这一种**；非门禁（big-M 四层加权）的实现路径已从代码中移除，
> 其讨论与设计理由整体归档于此，供论文 §3/§4/§5 引用与后人追溯，不再散落在代码注释里。

---

## 1. 最高裁定（不可动摇）

- **完成是约束，成本是目标。**
  形式化为 `min 成本(+迟到)  s.t. 完成所有可完成任务`（违反仅限 UNREACHABLE）。
- **生命周期铁律（2026-10-24 用户裁定）**：
  - 完成率（对*可完成集合*）恒为 100%——物理上能被完成的任务，给够周期迟早完成；
  - 唯一合法的非完成 = **物理永远不可达（UNREACHABLE）**；
  - 任何出现的 **淘汰（elim）都 = 机制缺陷（bug）**，不是合法结果，审计须强制 `elim == 0`。
- 由此，**「多完成任务」不应写进搜索目标**，而应作为*约束*（可完成必完成）。这与
  2026-10-14「未完成合法性原则」一脉相承：完成率不是优化目标，真实目标是持续到达下
  尽可能多且正确地完成任务（指标：正确执行率、累计完成、废飞、淘汰=0、吞吐、等待）。

## 2. 两套口径对照

| 维度 | 非门禁（big-M 四层加权） | 门禁（coverage_gate） |
|---|---|---|
| 哲学 | 把「多完成任务」**写进目标**（−m·F1） | 把「该完成的必须完成」**做成约束** |
| 覆盖来源 | 被收益（巨大惩罚常数 m）**拉上去** | 由门禁（构造修复 + W_skip 层）**强制** |
| 搜索目标 f | `W_hard·n_hard + w_exc·excess_m − m·F1_eff + w_late·L + λ·path + w_time·F3` | `W_hard·n_hard + w_exc·excess_m + W_skip·n_skip + w_late·L + λ·path + w_time·F3` |
| F1 地位 | 目标项（主导阶梯，m·F1 量级 ≈ 2.7e7） | **事后指标**（只计数，不进 f） |
| 约束等价 | 无显式覆盖约束；靠罚函数近似 | voluntary_skip 与物理硬约束等价（非法解） |
| 与最高裁定 | **冲突**（完成混进目标、本质罚函数近似） | **一致**（完成是约束、成本是目标） |

### 2.1 非门禁（big-M 四层加权和，近似字典序）

```
f = W_hard·n_hard + w_exc·excess_m       # T0 物理硬违约
  − m·F1_eff                              # T1 交付收益（含迟到折减）
  + w_late·L_tot                         # T2 迟到（软，秒级）
  + λ·path + w_time·F3                   # T3 航程 / 负载均衡
```

- `m`（big_m）是字典序支配权重，默认按 `_auto_big_m` 推导
  `m = 1 + 次目标上界 / 最小正收益`，保证「多完成 ≥1 个任务」压倒任意次目标差异。
- 覆盖是**被收益拉上去的**：靠 m 的巨大量级把完成数硬拽起来。
- **机制缺陷（为什么被淘汰）**：
  1. `m` 是 `_secondary_upper_bound` 自动推导的**支配性权重**，且**随 λ 同步放大**
     （λ 1e-2→1e-1：m 276144→669115，2.4×）⇒ λ 调 10× 而 `|m·F1|:|λ·path|` 仅从
     8040:1→1819:1（4.4×）——**λ 是弱杠杆**，一半被 m 自适应追平；
  2. 迟到双计（−m·F1 折减 + w_late·L）；
  3. `w_late / λ` 交换律任意常数；
  4. m 随任务池漂移；
  5. 最致命：**「完成」混在目标里，本质是罚函数近似，不是真正的约束**——
     可行域被成本压满后会主动放弃可完成任务（见 §5 E1/E2），与铁律冲突。

### 2.2 门禁（coverage_gate，构造性合法条件）

```
f = W_hard·n_hard + w_exc·excess_m       # T0 物理硬约束
  + W_skip·n_voluntary_skip               # T0.5 覆盖门禁（与硬约束等价）
  + w_late·L_tot                         # T2 迟到（秒级软计价）
  + λ·path + w_time·F3                   # T3 航程 / 负载均衡
```

- **搜索用 f 不含 −m·F1；F1 只作事后指标**。合法解中 S 内可装载任务已全部交付 ⇒
  F1 恒为常数、对解无区分度；保留 −m·F1 只会让 m 机制继续主导阶梯、把成本挤成
  tie-break（历史上 λ·path 仅占 m·F1 的 1/5.7e5）。
- 覆盖由门禁承担：
  - **构造性修复**（stage 层 `coverage_gate=True`）：终态 `repair_coverage` 能救必救
    （插入现有航次 / 空闲机开班），修到不动点，`n_skip` 构造归零；
  - **W_skip 层**（`lexicographic_coverage=True`）：voluntary_skip 与物理硬约束等价，
    一次 skip 压倒任意交付收益（防御性，修复已归零时本层不咬合）。
- 两条进入路径由 `problem.gate_mode(solution)` 统一判定（开关开 或 `solution.meta`
  带 `gate_stats` 门禁产物），任一条成立即按门禁口径。

## 3. 门禁一阶检查语义（代码里「可装必须装」的精确含义）

对**每个「在 S 内但还没进任何 tour」的任务 j**，门禁做一阶可行性检查，大致两种模式：

- **模式 A — 开班（open）**：是否存在一架空闲机，单独接 j 再回某个合法终点巢，
  满足 航程 / 时间窗（自身窗）/ 巢容量 等硬约束。`coverage_gate._check_open`。
- **模式 B — 插入（insert）**：是否存在某条已有航次的某个插入位置，把 j 插进去后该
  航次仍满足硬约束（实现约定「自身窗」：只硬约束 j 自身到达 ≤ deadline，同航次后续
  任务被推晚属迟到（T2 软计价），不构成 skip）。`coverage_gate._check_insert`。

**判定规则**：
- 任一模式成功 ⇒ 判 **可装（loadable）**；
- 若仍未被任何 tour 接纳 ⇒ **voluntary_skip（非法解）**；
- 两种模式都失败 ⇒ 判 **一阶不可装（shortfall / capacity_shortfall）**，本周期允许
  不交付并记账（任务留池，下周期重试）。

⇒ **「可装必须装」在代码里的实际含义 = 一阶意义下可装 ⇒ 必须装**。
（「一阶」边界：只查「单任务插入」与「空闲机开班」两种模式，查不到
「j 单独装不下、与另一未覆盖任务拼一班才装得下」的组合可行——这是已知的一阶不完备，
`n_shortfall` 记录的是一阶检验失败，不是全局不可行证明。）

## 4. 为什么最终转向门禁

1. **与最高裁定一致**：完成是约束、成本是目标。门禁把约束写成构造性合法条件，
   目标层只剩成本 + 迟到 + 硬违约；非门禁把完成写进目标，本质是罚函数近似，
   与铁律（完成率恒 100%、淘汰=缺陷）冲突。
2. **λ 是真杠杆**：门禁下 m 退出主适应度阶梯，成本项不再被 m·F1 淹没，
   λ 的调节作用不再被 m 的自适应追平（见 §2.1 缺陷①）。
3. **覆盖可审计、可分离**：s_coverage / n_skip / n_shortfall 与 shortfall/淘汰 分账，
   避免「覆盖率指标单独说谎」（非门禁下 `s_coverage_rate` 分母会吞掉流失任务）。

## 5. 已知的门禁缺口（E1/E2，待修复）

门禁开启时曾观察到反直觉现象（2026-10-23 E1/E2）：完成率下降、淘汰出现
（G2：完成 57.0±2.45、淘汰 3，seed44 淘汰 6）。

**根因**：光靠终态 gate 不够——可行域被成本压满后**丧失装载余量**，剩余任务在一阶判据
里直接被判「装不下」→ 累积 shortfall。即「完成是约束」不能只靠终态门禁修复，
**可行域本身须保留装载余量**。

**修复方案（5 点，待用户裁定后实现）**：
1. 门禁下禁用 `prune_unprofitable`（与「完成是约束」冲突，会主动丢可完成任务换成本）；
2. 一阶检验升二阶（拼班 / 重排后再判），减少误判 shortfall；
3. polish 加「覆盖优先」局部搜索（不动主适应度阶梯，保住「f 不含 F1」）；
4. 重标定 `w_violation`（0.05~0.2 扫描，修复后迟到被 w_late 定价过低）；
5. 报告口径强制 s_coverage 与 shortfall/淘汰并列，防覆盖指标单独说谎。

> 注：据 §1 铁律，上述「淘汰出现」一律归为**机制缺陷信号**（门禁未达成「可完成必完成」），
> 不是「约束太硬」的副作用，也不是「假设被证伪」。

## 6. 最终裁定（2026-10-24）

- **门禁（coverage_gate）为唯一主口径，代码只保留这一种。**
- 非门禁（big-M 四层加权）路径已从 `scalar_fitness` / `gate_mode` 中移除；
  `lexicographic_coverage` 设为默认 `True`，`gate_mode` 恒返回 `True`。
- 旧口径的全部讨论、数学形式、机制缺陷与历史实验数字，统一归档本文件，
  供论文引用，不再散落于代码注释。
- 历史对照数字（λ 扫描、E1/E2、exp01 A/B）见：
  `docs/OBJECTIVE_REFRAME_2026-10-22.md`、`experiments/EXPERIMENT_REPORT_E1E2_2026-10-23.md`、
  `docs/fitness_path_optimization_diagnosis_2026-10-24.md`。
