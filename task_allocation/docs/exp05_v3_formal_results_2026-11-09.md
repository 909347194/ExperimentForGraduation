## 1. 第 0 层门槛：先修实现缺陷，再看真实结果

首次汇总报「门槛 12 个失败单元 / M0 一致性 False」。按「**审计 FAIL 先怀疑实现缺陷**」逐项核对，确认两处是判据 bug：

1. **恒等式重复计数**：`check_invariants` 用
   `arrived = done + unreachable + dormant_end + remain`，但
   `n_remaining_pool = len(pool)` **已包含末态休眠任务**（休眠不出池）。
   真实数据 `M0/seed44`：51 + 4 + 5 = 60 已闭合，重复加 5 个 dormant 后假报失败。
   修为 `arrived = done + unreachable + remain`，与项目铁律一致；
   `metrics.py` 的同名注释一并修正。
2. **类型比较错误**：`consistency_equal_all` 落盘为 `int(0|1)`，判据却用
   `is True`，导致全部通过的逐位一致性被误报为失败。改为 `bool(...)`。

两处各补 1 例回归测试。**修后 35 单元的恒等式全部闭合**，
`m0_all_equal=True`、`eliminating=0`、`n_hard_violations_total=0`、
`n_unreachable_service=0`（服务不可达全零，不可达一律为几何不可达 3–8 个/seed）。

### 剩下的 5 个失败单元是真实负向结果，不抹平

| 方法 | seed | 完成率 | n_done / 不可达 / 末态休眠 / 池中剩余 | 失败项 |
|---|---|---|---|---|
| M0 | 43 | 0.980392 | 50 / 8 / 1 / 2 | `completion_rate_is_one` |
| Q0 | 43 | 0.980392 | 50 / 8 / 1 / 2 | 同上 |
| B1 | 43 | 0.980769 | 51 / 8 / 0 / 1 | 同上 |
| B2 | 43 | 0.980769 | 51 / 8 / 0 / 1 | 同上 |
| B3 | 43 | 0.980769 | 51 / 8 / 0 / 1 | 同上 |

即 **seed 43 有 1 个「非几何不可达、非末态休眠」的任务没有被完成**；
D0 与 B2e 在该 seed 完成率为 1.000。停机原因来自日志：
M0 / Q0 跑满 `n_cycles=60` 安全上限仍非空池；B1 / B2 / B3 是
「连续 4 周期零进展，`stable_patience` 兜底，非自然收敛」。
其余 4 个 seed 的 28 个单元全部 1.000、自然收敛（池空），
加上 seed 43 通过门槛的 D0 / B2e，共 **30/35 单元**完成率为 1。

**结论口径**：本正式档**不能写「完成率恒 100%」**。完成约束在 30/35 单元成立，
seed 43 是反例；这是**早停判据 / 滚动预算的待修机制缺陷**，不是
「完成率可以与成本权衡」的证据（项目铁律：完成是约束）。
`primary_gates_passed=False` 必须保留在报告里，逐格归因，不得静默删除。

## 2. 五条主张的正式档裁决

### C1 完成是硬约束 —— 部分被推翻，须如实声明

- 5 seed × 7 方法均值：M0 0.996078、D0 1.000、B1/B2/B3 0.996154、Q0 0.996078、B2e 1.000。
- 不变量层面全部通过：`arrived = done + unreachable + remain` 35/35 闭合，
  `n_eliminated=0`、硬违约 0、服务不可达 0、按时率（交付集）≥ 0.996。
- 但 seed 43 的 5 个单元未达 1.000（见 §1）。**可写**：「在本场景 30/35 单元
  完成约束成立；seed 43 的 5 个方法因滚动早停各遗留 1 个可完成任务，已逐格归因」。
- **禁写**：「所有可完成任务均被完成」「完成率恒 100%」「完成与成本可权衡」。

### C2 换尺子是否改变结论 —— 唯一推断主判据未检出差异

唯一推断主判据 `ruler_effect` = 逐 seed
`(M0−D0)@DEM − (M0−D0)@三维直线`（单位 m）：

| seed | 42 | 43 | 44 | 45 | 46 |
|---|---|---|---|---|---|
| Δ@DEM | +45493.410 | −27762.569 | −43240.359 | −1160.711 | +6090.012 |
| Δ@三维直线 | +45206.967 | −26669.835 | −40144.428 | −245.052 | +5915.589 |
| **差值之差** | **+286.443** | **−1092.734** | **−3095.931** | **−915.659** | **+174.423** |

配对统计（df=4）：均值 **−928.6916 m**，std 1361.747，
t = **−1.524966**，双侧 **p = 0.201956**，Cohen's dz = −0.681985，
95% CI **[−2619.524, 762.141]** ⇒ 三态结论 **`inconclusive`**。

描述性证据（**不出三态结论**）：

- `ruler_changes_direction = False`：5 个 seed 的 M0−D0 差值在两把尺子下
  **符号全部一致**（+ + − − + 两种尺子同号），即本场景下换尺子**没有改变方法间
  差值的方向/排序**；只改变量级（逐 seed 差 174–3096 m，均值 929 m）。
- 同一批解的尺子绝对差 `path_m_audit − path_m_euclid3d` 均值：
  M0 14072.693 m、D0 15001.384 m、B2 14142.525 m、B1 20966.191 m。
  这是定义性事实（绕地形/爬升的三维航程 ≥ 直线），只报量级。
- 比值 `d_DEM/d_euclid3d` 均值：M0 1.053040、D0 1.055475，
  M0−D0 逐 seed 比值差均值 −0.002435（4 负 1 正）⇒ 偏差因方法而异，
  但幅度很小且不稳。
- M0 vs D0 描述性配对：`path_m_audit` 均值 −4116.043 m（p=0.800848）、
  `path_m_euclid3d` −3187.352 m（p=0.839480）、`f_audit` +1088.600（p=0.511290）。

**结论口径**：只能写「**本实验未检出**换尺子对方法间差值之差的显著影响
（p=0.202）；描述性上两把尺子的量级差为 0.2–3.1 km，5 个 seed 的差值方向一致」。
**禁写**：「评价口径改变结论」已被证实、「无差异 / 等价」、
「DEM 让航程更短」、把 `ruler_gap>0` 的显著性当作发现、
「本实验证明求解端必须用 DEM」（D0 是复合档，且只换了评价端）。

另有一处口径限制必须声明：M0 与 D0 在 seed 43 的交付任务集不同
（50 vs 51 个完成），该 seed 的 Δ航程不是同任务集比较。

### C3 交付解可独立重评 —— 支持

- 35/35 单元 `consistency_equal_all=1`、`audit_errors=[]`、
  `n_audit_unavailable=0`、`n_audit_ok = n_audit_cycles`；
  M0 自报航程与几何重建 DEM 重评之差在 **±0.04 m** 内（浮点尾差）。
- D0 / B2e 的 `total_path_m − path_m_audit` 为 −13.7 ~ −18.3 km，是**预期**
  （自报为欧氏、重评为 DEM），不是不一致；正好说明跨方法不能各用各的尺子。
- 剩余 failures 全部是 `single_cycle_completion_scope`（单周期口径退化：
  skip/shortfall 导致单周期候选未全执行），共 210 项，按方法
  M0 70 / Q0 70 / B1 18 / B2 17 / B3 12 / B2e 12 / D0 11；
  M0/Q0 偏多源于 seed 43 跑满 60 周期。**跨周期完成率由 C1 判定**，
  该项不计为自报/重评不一致。
- **可写**：「本文方法交付解可被逐周期几何重建独立重评，自报与重评逐位一致」，
  exp08/exp09 记为技术债的几何重建重评在 exp05 v3 已接通。

## 3. 正式档暴露的实现缺陷与待办（按优先级）

1. **完成约束在 seed 43 被破坏**（最高）：`stable_patience` 兜底与 60 周期
   安全上限在「池里仍有可完成任务」时停机。须查停机判据（区分
   「暂时不可服务」与「能力范围外」），修到 0；**未修前论文必须如实声明反例**。
2. **`f_audit` 未统一评价尺子**：`IndependentEvalHook` 捕获的是各方法自己
   构造的 problem 实例，D0 / B2e 的 `f_audit` 仍按欧氏自报路径算
   （如 D0 均值 27075.485 ≈ 0.1 × 自报 270754.86，而非 0.1 × DEM 重评
   285756.24）。`path_m_audit` 才是统一 DEM 口径。主表 `f_audit` 列属混尺子，
   跨方法比大小前须标注；修法须让逐周期重评强制使用 DEM 估计器，
   **本轮未擅改生产链路**。
3. **`f_audit` 与航程不同量纲**：skip / hard / late 惩罚项可主导 f
   （B1 即为例）。C4 只用其描述性，不作质量排序。
4. **单周期口径退化** 210 项仍是技术债（§2 C3），须单独收口。
5. **外效度**：单场景、单到达流、5 seed（df=4）；名义 p 未做多重比较校正；
   禁跨场景 / 跨实验配对 t 检验；冒烟与 mid 档结论不可外推正式档。

## 4. 论文可用措辞 / 红线

**可写**

- 「在 35 个方法×seed 单元中，30 个满足完成约束；seed 43 的 5 个方法因滚动早停
  遗留 1 个可完成任务，已逐格归因，未检出淘汰或硬违约」。
- 「本文方法交付解可被逐周期几何重建独立重评，自报与 DEM 重评逐位一致
  （差 ≤0.04 m）」。
- 「同一批交付解换用三维直线重算，航程量级差 0.2–3.1 km；本实验
  未检出其对方法间差值之差的显著影响（p=0.202，双侧配对 t，5 seed）」。
- 「评估次数与墙钟同列于主表，质量—代价前沿只作描述」。

**禁写**

- 性能提升 / SOTA / 独立收益 / 协同效应 / 双双验证；
- 「完成率恒 100%」「无差异 / 等价」「换尺子改变结论已被证实」
  「求解端必须用 DEM」「MCF 全局最优 / 无用 / 可删」；
- 把 `f_audit` 与 `path_m_audit` 的 p 值当作两条独立证据；
- 把 C4 描述性名义 p（含 0.0447）写成推断结论；
- 把冒烟 / mid 档、旧 `results/`（已冻结）或旧 λ / −13% / −15.8pp 数字写入论文。
