# exp05 E1 收窄设计定稿（2026-11-13）

> **定位（用户裁定）**：exp05 只服务一条主张 **E1**——
> 「**不是随便一个可行分配也能做到整体有效性**」。
> 即用基线对照证明本文方法的整体有效性**不是平凡可达的**：随便一个可行分配
> （随机落位）、稍微认真一点的构造式（贪心插入）、乃至同架构但把距离模型
> 换成平面近似，都达不到本文方法在「完成是硬约束、成本是目标」下的表现。
>
> **这不是排行榜**。不回答「我们是否比启发式更好」，不产生任何「性能提升 /
> 优于 / SOTA」结论；E1 是**否定平凡解**的可证伪论证（平凡可达性被证伪才算
> 支持），与阶段二「不主张清单」一致。
>
> **冲突裁决**：本文件与
> `docs/exp05_redesign_2026-11-09.md`（v3 五主张）、
> `experiments/exp05_baselines/notes.md` 的 v1/v2/v3 段落冲突时，**以本文件为准**；
> 全局铁律以 `docs/stage2_final_scheme_2026-11-06.md` §11 为准。
>
> **本轮范围（2026-11-13）**：只做**设计与更改 exp05 实验**（配置 / 主张 /
> 编排 / 参照表 / 文档 / 回归测试）。**不跑实验**。正式档须用户单独发话跑批
> （项目铁律：严禁多实验并行、正式档单独跑批、冒烟结论不外推正式档）。

## 0. 为什么从 v3 收窄

v3 把 exp05 设成「C1–C5 五条主张的检验台」，7 个对照方法。正式档
（`docs/exp05_v3_formal_results_2026-11-09.md`，7×5=35 单元）暴露四点：

| # | 问题 | v3 正式档事实 |
|---|---|---|
| 1 | **唯一推断主判据近零效应** | C2 `ruler_effect`（两把尺子的差值之差）均值 −928.692 m、**p=0.201956**、dz=−0.682 ⇒ `inconclusive`；5 seed 方向 5/5 同号，只改量级不改方向。df=4 下几乎检不出 |
| 2 | **臂冗余 / 口径不齐** | Q0（小预算档）只服务「质量—代价前沿」描述、B2e（距离×求解范式双因素）与 B3（硬时间窗主动跳任务、完成率≠1）本就只进附表，对 E1 无贡献却拉长跑批、混入异口径 |
| 3 | **评价端主表混尺子** | `f_audit` 由各方法自己的 problem 重评，D0/B2e 仍按欧氏自报路径算；B1 的 f 被单个 skip 惩罚主导到 1e7–1e8 量级 ⇒ 不可跨方法比大小 |
| 4 | **门槛反例仍在** | seed 43 有 5 个单元因滚动早停各遗留 1 个可完成任务 ⇒ C1「完成率恒 1」被部分推翻，`primary_gates_passed=False` |

收窄动作对应用户三项裁定：

- **主张收窄**：C1–C5 五条 → **E1 一条**；两把尺子对照（C2）、组件去留索引
  （C5）整条删除，C1/C3 降级为**门槛层断言**（不是成绩、不排序）。
- **方法收窄**：7 → **4**（M0 / B1 / B2 / D0）；删 Q0、B2e、B3。
- **评价端收窄**：多把尺子 → **同一把三维代价尺**：所有 4 个方法的交付解
  一律用**垂直切面 DEM 有向三维航程**几何重算（`path_m_audit`）后比较。

**收窄的统计收益（重要）**：主判据从「两把尺子的差值之差」（量级 0.2–3.1 km、
方差大、近零效应）换成「随便一个可行分配 vs 本文方法」的每完成航程差（构造式
下界与联合优化框架之间是**量级性**差距）。单一大效应主判据在 5 seed、df=4 下
功效显著高于 v3 的 C2，且**同时消除了多重比较**（只有一条推断主判据）。

## 1. E1 主张（唯一，可证伪）

**主张句（论文可写）**

> 本文方法的整体有效性**不是随便一个可行分配也能做到**：在完成作为硬约束、
> 成本作为目标的前提下，把三个「平凡 / 次优」对照——随机可行分配、收益/代价
> 比贪心插入、以及同架构但把规划距离换成平面近似——与本文方法放在**同一把
> 垂直切面 DEM 有向三维航程尺**下重评，前者达不到本文方法同时守住完成约束
> 与压低每完成航程的水平。

**操作化（可证伪）**

- **零假设 H0**：随便一个可行分配（以 B1 随机可行分配为锚）与本文方法在统一
  DEM 尺下的**每完成航程**无方向一致的可检出差异（即「平凡可达」成立）。
- **主判据**：`M0 − B1` 的 `path_m_audit / n_completed` 逐 seed 配对差，
  `expected = negative`（M0 更省）。三态结论判据写死（§5）。
- **证伪方向**：若 B1 反而显著更省（`not_supported`），或差异未检出
  （`inconclusive`），E1 均**不被支持**，须如实写、并查实现 / 修订主张。
- **不主张**（红线，逐条硬约束）：
  - 「性能提升」「全面优于现有方法」「SOTA」「显著优于基线」；
  - 「M0 完成率更高」——完成率是正确性不变量，由共享滚动外壳承担，不排序；
  - 把「M0−B1 差异被检出」写成「本文方法更优的排行榜结论」——它是
    **平凡可达性被否定**，不是优越性宣称；
  - 把差异**归因到某个组件**（DMDE / MCF / polish / 终点机巢分层）——
    B1/B2 与 M0 是**整个第二阶段求解范式**差异，D0 是复合档，均非单因素；
  - 「本实验证明求解端必须用 DEM」（D0 连 ETA / 时间窗动力学一起换）。

## 2. 四个对照方法（7 → 4）

| ID | 直白名称 | 求解器 | 求解端距离 | **评价端距离** | 在 E1 里的角色 |
|---|---|---|---|---|---|
| **M0** | 本文完整方法 | dmde | DEM 有向 | **DEM 有向（唯一比较尺）** | 被检验对象（锚点） |
| **B1** | 随机可行分配 | random | DEM | **DEM 有向** | **「随便一个可行分配」的直接代表，主判据对照** |
| **B2** | 收益/代价比贪心插入 | greedy | DEM | **DEM 有向** | 描述性梯度：稍微认真一点的构造式也非平凡可达 |
| **D0** | 同架构、规划距离换平面近似 | dmde | 欧氏 | **DEM 有向** | 描述性梯度：求解框架不变、距离模型换平面近似也非平凡可达；**复合档，禁单因素归因** |

**删去的 3 个（旧 7 臂，一律不进主文）**

| ID | 删除理由 |
|---|---|
| **Q0** | 同架构小预算档（pop8×gen8），只服务 v3 C4「质量—代价前沿」描述性点；E1 不需预算档，且它是 M0 的弱化版不是「随便一个可行分配」 |
| **B2e** | 贪心 + 平面近似，**距离 × 求解范式双因素**，不可单因素归因；与 B2 / D0 语义重复 |
| **B3** | 硬时间窗 VRPTW，**主动跳过任务导致完成率≠1**，与「完成是硬约束」同口径冲突，属异口径附表方法 |

**保留的四点理由**：① 四者全部 `primary=true`、同一软时间窗口径、都不主动
跳任务，可放进同一张主表配对；② 覆盖「随便 → 认真构造 → 同架构换模型」的
平凡性谱系；③ B1 是「随便一个可行分配」的字面锚，主判据唯一；④ 全场景同
`lasa_chengguan`（6 巢 / 20 km），与 v3 正式档重评口径可比——**场景不随收窄改**。

## 4. 统一事后评价器：**同一把三维代价尺**

**唯一比较尺 = 垂直切面 DEM 有向三维航程**（`path_m_audit`，
`post_eval.recompute_two_rulers` 对交付解 `solution.json` 的逐周期 tours
按实际飞行方向逐腿几何重算）。4 个方法的**同一批交付解**一律用这一把尺重评，
与求解端解耦——这是 E1 公平比较的前提。

| 列 | 地位 | 说明 |
|---|---|---|
| `path_m_audit` | **唯一比较尺 / 主表** | DEM 有向三维航程，几何重算，所有方法同口径 |
| `path_m_audit / n_completed` | **主判据** | 逐 seed 先归一再配对；分母 ≤0 显式记未配对、不补 0 |
| `on_time_rate_final` / `reward_yield` | 描述性 | 体现「整体有效性」的时效/产出一面，**不出 verdict** |
| `n_evals_total` / `wall_seconds` | 代价并列 | 与质量同列；墙钟只作观测、不可跨实验横比 |
| `path_m_euclid3d` / `ruler_gap_m` | **仅诊断留档** | 几何重算副产物；**不进任何主张 / 主表 / 参照表** |
| `f_audit` / `total_path_m` / `path_per_completion_m` | **留档，不进主文比较** | 混尺子或自报尺；`f_audit` 含 skip/hard/late 惩罚项，与航程不同量纲 |
| `completion_rate` 类 | 门槛断言 | 正确性不变量，不排序 |

与 v3 的差异：**删除「两把尺子」主张与 `ruler_effect` 主判据**。几何重算仍
同时产出三维直线（零额外求解、纯诊断），但主张层只认 DEM 一把尺；
`evaluation.two_rulers` 更名为 `evaluation.compute_euclid_diagnostic`（语义：
仅留档），新增 `evaluation.primary_ruler: dem_vertical_section_3d` 落进
`run_meta.json`。`post_eval.py` / `metrics.py` 的几何重算能力与尾插列**保留**
（资产 + 回归测试依赖），只改文档口径。

**独立重评一致性**：`IndependentEvalHook` 逐周期几何重建重评，自报 vs 重评
逐位一致（`consistency_equal_all`）作为第 0 层门槛断言保留；审计 FAIL
只记账、不中断，**先怀疑实现缺陷**。单周期完成率门槛的口径退化
（`single_cycle_completion_scope`）不算不一致，跨周期完成率由门槛层判定。

## 5. 统计协议

- **seed**：`[42, 43, 44, 45, 46]`（与 v3 同协议，重评口径可比）。
- **单一推断主判据**：`E1.primary_pair = M0 − B1` 的 `path_m_audit_per_completion`。
  只有这一条出三态结论 ⇒ **无多重比较问题**，名义 p 仍需声明 df=4、单场景、
  单到达流、未做校正（沿用 CAVEATS）。
- **配对**：逐 seed 取差；`paired_seeds` / `unpaired_seeds` 显式落盘，
  缺配对即门槛失败、不得静默丢弃。
- **检验**：Student t 双尾**精确** p（正则化不完全 β，不用正态近似、不依赖 scipy）；
  零方差 ⇒ `zero_variance_no_test`，不写「不显著」；`n_pairs<2` 不检验。
- **报告量**：`per_seed` / 均值 / 标准差 / `t_stat` / `p_two_sided` / `p_reason` /
  95% CI / Cohen's `dz` / `significant_at_0_05`。
- **三态结论**（判据写死，禁止事后调整）：
  - `supported`：方向 negative（M0 更省）**且** `p<0.05` **且** `|dz|≥0.5`；
  - `not_supported`：方向相反**且** `p<0.05`；
  - `inconclusive`：其余（含 p 不显著、零方差、配对不足、效应量过小）。
  - 措辞固定：`supported` = 「本实验否定了『随便一个可行分配也能达到同样
    整体有效性』」；`inconclusive` = 「本实验未检出差异」，**禁写「无差异 / 等价」**。
- **描述性档**（M0−B2 / M0−D0 / 绝对量 / 代价）：只给估计量与区间，
  **不产出 verdict**，防止被下游误读成「方法优劣结论」。

## 6. 主张 → 对照 → 指标 → 判据 → 写作口径

| 项 | 内容 |
|---|---|
| 主张 | E1「不是随便一个可行分配也能做到整体有效性」 |
| 主对照 | **M0 vs B1**（随便一个可行分配） |
| 主指标 | `path_m_audit / n_completed`（统一 DEM 有向三维航程，逐 seed 归一） |
| 判据 | 配对精确 p + dz + 三态结论（唯一推断） |
| 描述性对照 | M0 vs B2（贪心）、M0 vs D0（同架构换平面近似）+ 时效/产出/代价 |
| 允许的写法 | 「在同一 DEM 三维尺重评下，本实验**未支持**『随便一个可行分配也能达到同样整体有效性』（配对差 …，p=…）」；「B2/D0 的描述性差距为 …，不作推断结论」；「完成约束由共享滚动外壳承担，seed 43 的遗留任务已逐格归因」 |
| 禁止的写法 | 「性能提升 / 显著优于基线 / 全面优于 / SOTA」；「M0 完成率更高」；把主判据写成排行榜结论；把差异归因到单组件；「求解端必须用 DEM」；「完成率恒 100%」；把 `f_audit` 与 `path_m_audit` 的 p 当两条独立证据（`Δf=0.1·Δ航程` 是线性缩放）；把描述性名义 p 写成推断结论 |
