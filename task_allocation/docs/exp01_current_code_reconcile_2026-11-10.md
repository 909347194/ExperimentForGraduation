## 5. 两条口径红线（本次实测再次确认）

1. **`f = 0.1·path + 0.01·late_s` 精确成立**：9 个有作业周期的残差全为
   `0.00e+00`。故 `f` 与航程的差值是同一量的线性缩放，**不是两条独立证据**；
   迟到项只是第二个加数。
2. **`total_f2` 混加米与秒**（`w_penalty=1`，`f2 = path + penalty`），
   `metrics.py` I3 已声明「量纲不同不能混加后当总路径代价」。
   本批次 seed 42/43 的 `total_f2 − total_cost` = 9.033 / 84.301，恰为迟到秒数，
   不是航程，**禁止当航程引用**；航程一律用 `total_path_m` / `total_cost`。
