# M2 基因回写（Lamarckian 反射写回）实现边界设计

> 状态：设计稿（2026-10-30），**动基因编码前先冻结边界**。
> 目标：覆盖饱和后让搜索继续压路径成本/软违约——把 polish/修复出的更优序
> **写回基因**，使后继代际的差分围绕改进后的可行子空间展开
> （治 T9「基因型坍缩后无梯度可爬」）。M1（精英 polish 档案）A/B 进行中。

## 0. 先读懂基因契约（写回的物理基础）

- 基因 = 三元组 `(uav_id, target_id, cost)`；个体基因数**恒为 N**
  （每任务恰出现一次）。
- **遗传载体是 `Individual.cost_vector`（固定布局连续向量）**，DE 差分只
  作用于它（`encoder.py` 契约）：

  ```
  [0, K)   起始槽：UAV i → 首任务的 cost_matrix 指纹（按 UAV 下标升序）
  [K, N)   巡游槽：任务 → 任务的代价指纹（按出现顺序）
  ```

  `target_id`/`uav_id` 是**解码锚点**——`inverse_phi` 的贪心匹配从 cost 值
  指纹反推离散对。⇒ **写回 = 改 cost 指纹 + 对齐解码锚点**，两件事缺一不可。

- 通道三分：

  | 通道 | 内容 | 现状 |
  |------|------|------|
  | 起始通道（uav_id ≥ 0） | 归属 + 巡游首任务 | M1 已回写 target_id+cost |
  | 巡游通道（uav_id = −1） | 段内访问顺序链 | **保留原样 ← M2 主战场** |
  | 终点机巢 | 不进编码（方案 A） | 永不写回，内层 min-cost flow 精确求解 |

- 三大不变式（写回绝不可破）：
  - **I1 长度不变**：基因总数 == N；
  - **I2 唯一性**：target_id 是全排列（每任务恰出现一次）；
  - **I3 段结构**：K 条起始基因（uav_id 各异）+ N−K 条巡游基因，巡游基因
    归属于其**前一条起始基因**的 UAV（`normalize_srp_segments` 契约）。

## 1. Q1：哪些基因段可安全写回

| 段 | 可否 | 写什么 | 约束 |
|----|------|--------|------|
| 起始通道 target_id + cost | ✅ 已做（M1） | 该机修复解首任务 | 只改字段，不增删 |
| 巡游通道**段内** target_id 排列 + cost 重算 | ✅ **M2-1** | 同机调序收益（2-opt / Or-opt） | I1/I2/I3；只重排本段巡游基因的 target_id 序列，cost 按新链逐段重算 |
| 巡游通道**跨段**迁移 | ✅ **M2-2（二期）** | 改派收益（relocate） | 段长重分配：巡游基因在段间移动（总数仍 N、每任务一次），起始基因不动 |
| uav_id 通道重构（拆并段） | ❌ 不做 | 归属结构变化 | 交 SRP 反映射 + 起始通道回写；第一版不碰 |
| 终点机巢 | ❌ 永不 | — | 方案 A 不进编码 |
| 被剔除任务（_prune/_repair_range 删掉的） | ❌ 保持现状 | 其巡游基因**原样保留** | 下轮 decode 重现再剔除；基因层增删会破 I2（现有保守设计，理由充分） |

**通用纪律：只写"修复后表型"，不写"搜索中间态"**——回写源必须是过了硬闸
（n_hard==0）+ 时序归位后的解。

## 2. Q2：写回后是否强制再跑轻量 repair

**要，但不是全量 build_solution**，而是三层校验 + 最小归一：

1. **解码一致性校验（必须）**：写回后以 `temperature=0`（纯开发、无扰动）
   重解码一次，表型必须 == 目标修复解（归属集合 + 各段顺序）；不一致 →
   **回退原基因**（fail-safe，与现 `lamarckian_reencode` 返回 None 回退同纪律）。
   为什么必须：`inverse_phi` 带温度扰动（swap+reassign+SRP 巡游扰动），
   写回的 cost 指纹可能被反映射"表达漂移"——校验保证 Lamarckian 语义
   （基因=表型）成立，否则写回只是噪声。
2. **轻量 repair（必须，只跑确定性归一算子）**：`_sequence_fix`（链激活时
   时序归位）。**不跑** `reorder_for_deadlines` / `repair_range` /
   coverage gate——它们是搜索语义的一部分，写回时跑等于把刚写进的序
   又洗掉（T9 病根之一）。
   写回源本身已过完整修复链，无需再做可行性修复；此处只保证
   "基因表达序 == 修复序"。
3. **不变式断言（必须）**：I1/I2/I3 逐条校验，任一破 → 回退。

不建议"写回后强制全量 repair"：全量链含重排会重新洗序（写回白做），
且每代一次全链太贵。

## 3. Q3：如何避免把种群拉回"高覆盖但高违约"区域

风险源：劣质/未修复表型入基因 → 后继差分围绕它 → 种群被拖回违约区。四层防线：

1. **写回源过滤（最重要）**：只有 `n_hard == 0` 且覆盖 ⊇ 回写前表型的解
   才允许写回；**含硬违约的解永不写回**（无论 fitness 多好看）。
2. **fitness 不变式 + 表型复核**：写回只改表示、不改 fitness
   （`re_encoded.fitness = child.fitness` 现纪律保留）；但新增表型复核——
   重解码表型的 `(n_hard, 覆盖, 迟到)` 三元组必须逐分量**不劣于** child 的解，
   否则回退。防"fitness 是旧的、表型是新的"错位。
3. **范围控制**：只写回获胜子代/精英（每代 ≤ 1 个），不广播全种群、
   不写灭绝重置个体；`best_individual` 拷贝语义不变。
4. **多样性监控护栏（转正门槛，非运行时熔断）**：记录写回后代际的
   cost_vector 种群方差；若方差加速坍缩 → 作为 A/B 否决指标。
   不做运行时熔断——保持求解确定性。

## 4. 实现分期与验收

| 期 | 内容 | 验收 |
|----|------|------|
| M2-1 | 段内序回写（扩 `lamarckian_reencode` 的巡游通道段内重排） | I1/I2/I3 断言 + 解码一致性 + 3 seed A/B（路径成本 / 迟到 / 收敛曲线 / 种群方差） |
| M2-2 | 跨段迁移回写（段长重分配） | 同上 +"改派收益保持"用例 |

测试清单（`test_lamarckian_writeback.py`）：

1. 段内序写回后重解码 == 修复序；
2. I1/I2/I3 任一破坏时回退原基因；
3. 硬违约解**永不**写回；
4. 表型复核 (n_hard/覆盖/迟到) 逐分量不劣才接受；
5. 开关关闭时与现行为**逐位等价**。

回退纪律全程：任何异常/不一致 → 原 child，stderr 警告一次、不静默
（沿用「回退永不静默」惯例）。

## 5. 与 T9 教训的关系

T9：SRP 反映射锁归属 + 只回写起始基因 → 归属逐代复现、闲置槽死维度、
基因型坍缩。M2 两期把**顺序**自由度纳入可遗传空间。但警惕反噬：写回也会
**加速**精英基因扩散（同质化）——§3.4 多样性监控是转正门槛；若 A/B 显示
方差坍缩加速而成本增益不稳，回退到 M1-only（档案不写回）。

## 6. 实现澄清（2026-10-30 落位后补记）

M2-1 已实现并通过 6 项单元测试 + 全量 326 测试零回归；以下把设计稿几处
"字面 vs 实现"的取舍显式记录，避免后续评审歧义。

1. **M2-1 借道 M1 调用门（对应 Q1/Q2 范围）**：`dmde_solver` 的回写入口是
   `if cfg.lamarckian and hasattr(...)`，**`lamarckian=False` 时 M2-1 永不触发**。
   M2-1 不能脱离 M1 单独开启，是 M1 同一回写调用的扩展（同时改写起始 + 巡游通道），
   关闭时逐位等价于历史起始通道写法。
2. **Q3.3「每代 ≤ 1 个」按调用点粒度实现，未做运行期硬计数上限**：当前写回发生在
   "获胜子代"分支且仅针对当前个体（天然不广播全种群、不写灭绝重置个体），粒度继承自
   M1。若加硬上限会同时改变 M1 行为、破坏"开关关闭时与历史逐位等价"，故选择不实现为
   运行期熔断。如后续需要"仅 M2-1 生效的 ≤1/gen 硬上限"，可单独加、不影响 M1 parity。
3. **Q3.1 第二句「覆盖 ⊇ 回写前表型」被段内重排结构性满足**：段内重排只改顺序、不改
   任务集合，覆盖在结构上不变；实现仍在 Q3.2 显式复核 `cov_reb ≥ cov_src`（重解码 vs
   修复源），作为二次保险。
4. **Q3.4 多样性监控按"转正门槛、非运行时熔断"定位（与 §3.4 原文一致）**：已实现
   `dmde_solver.population_callback` 钩子（默认关、零开销、异常即停用），记录代际
   `cost_vector` 种群方差供 A/B 作为否决指标；**未加任何运行期方差熔断**，保持求解确定性。
5. **A/B 实证结论（多实例配对，6 实例 × 3 种子）**：M2-1 为**情境性增益**——仅当修复链
   因截止压力重排段内序的实例上显现（最大 ≈20% 路径成本下降），无截止压力时中性；
   两分支均未加速种群同质化（方差坍缩 9 胜 8 负 ≈ 持平）、零硬违约、全覆盖。建议维持
   默认关，在"截止压力重 / 路径成本权重高"工况按需 opt-in。
