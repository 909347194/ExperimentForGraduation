## 目的

在 **固定场景与随机种子协议** 下，一次只改一个（或极少）因素，验证第3章关键设计是否“有用且可解释”，而不是调参碰运气。

重点机制：

1. 适应度层级（四层准字典序 / T0 硬违约支配）
2. 迟到折减窗 \(W\)（与“迟到≠废飞”协议）
3. 解码修复链（航程修复、合并闲置、零奖励剔除开关）
4. 终点机巢策略（方案 A：解码后 MCF vs 固定返巢；可选方案 B 进编码）
5. （可选）Lamarckian 回写、选择层开/关（与 exp02 交叉引用）

## 消融矩阵（建议）

> 原则：**同一 `scenario_id` + 同一 `seeds`；每次相对 A0 只动一列。**

| 变体 ID | 相对 A0 的改动 | 验证假设 |
|---------|----------------|----------|
| **A0** | 生产默认：四层适应度 + \(W=1800\) + 方案 A 终点 MCF + 修复链开 | 基准 |
| **A1** | 关闭 T0 / 或改回旧加权和 `lexicographic: false` | 层级支配是否必要 |
| **A2a/b** | \(W=600\) / \(W=1800\)（可再加一档） | 迟到折减是否把“可接受迟到”打成“废飞” |
| **A3** | `prune_zero_reward` 开/关 | 零奖励剔除是否改进适应度或反而扰动搜索 |
| **A4** | 关闭航程修复或合并闲置（择一） | 可行性主要靠搜索还是靠修复 |
| **A5** | 终点：固定返回起飞机巢（或最近巢启发式） | 相对 MCF 异源终点的航程/可行差异 |
| **A6** | （可选）终点进编码方案 B | 仅讨论；默认不进主结论 |
| **A7** | （可选）选择层关闭，候选=全池（小 N） | 与 exp02 叙事对齐的小规模机制对照 |

已有资产：exp01 下适应度 A1/A2/A3 类结果应 **迁移为本矩阵可复现条目**，避免论文只引用聊天式笔记。

## 成功标准

1. **矩阵完整:** A0 + 至少 A1、A2、A5 跑通并落盘；每格有 metrics 与配置指纹。  
2. **单因素:** 除声明的组合行外，无偷偷同时改 \(W\) 与终点策略。  
3. **口径一致:** 有效完成率、零奖励交付、硬违约、航程、按时率定义与全局协议相同。  
4. **可解释:** 每个变体相对 A0 的指标升降能用机制解释（例如 \(W=600\) → 零奖励交付↑）。  
5. **不夸大:** 若 A5 差异很小，正文写“本实例下差异有限”，不硬吹。
