# 第一步：基因型 → 表型映射诊断（DE 是否真正控制最终解）

## 口径

- 对每个 DE trial 子代，`_evaluate_result` 同时给出解码前（基因 assignment）与解码后（修复链产出的 AllocationSolution）；指纹覆盖任务归属、任务顺序、执行任务集、实际参与无人机四字段，适应度单列。
- 单周期场景隔离跨周期混淆；生产默认 lamarckian=True、精修关（只看 DE+解码链）。
- `collision = 1 - 本代不同表型数/本代子代数`；`geno_to_pheno = 1 - 不同表型数/不同基因型数`；`new_pheno` = 本代首次出现的新表型数（= 真正改变最终方案的子代上界）。
- `de_elite_*` 来自 `cost_history`（每代 best_fitness）：改进代数、最后一次改进代、冻结代占比、精英总增益、精英基因型改变代数。用于区分「表示坍缩」与「精英/选择停滞」两种病因。
