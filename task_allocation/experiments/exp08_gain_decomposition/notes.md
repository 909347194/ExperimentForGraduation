# exp08_gain_decomposition —— 交付后精修「几何 vs 归属」收益拆分

定稿 §11.4「P4 / 实验层待办」第 1 项：用 P3-b 的三本账
（`l3a_geometric_actions` / `l3b_relocate_actions` /
`n_task_to_uav_changes`）配合同 seed 配对留档。实验自持
config/build/paths/metrics/plot，不建 `_shared/`、不抽公共绘图包。

## 1. 要回答什么

交付后精修的收益里，多少来自**几何**（组内 2-opt/Or-opt、终点巢 MCF、
position），多少来自**归属**（跨机改派 relocate/swap）？两者是否能分开
归因？重点不是让每个模块都取得收益，而是确认每个模块解决什么问题。

## 2. 2×2 同 seed 配对

|  | 归属关 B=0 | 归属开 B=1 |
|---|---|---|
| **几何关 G=0** | `g0b0` | `g0b1` |
| **几何开 G=1** | `g1b0` | `g1b1`（生产口径） |

四档唯一差异用 `dataclasses.replace(stage_model, ...)` 锁定，只允许
`cost_polish_enabled` / `l3b_enabled` / `polish_moves` /
`cost_polish_accept_mode` 四个字段不同；逐 seed 核验配置纯度。
采纳判据四档统一 `f`（定稿 §11.9）。同一 seed 跑完四档再进下一个 seed，
按 seed 交替档序抵消缓存预热偏差；**严格串行，不并行任何实验**。

报告口径：逐档质量指标、三本账、**主效应 + 交互项并列**
（`interaction = (f00−f01) − (f10−f11)`）、配对 t 检验
（精确 Student t，正则化不完全 β；零方差标 `zero_variance_no_test`）。
**禁写「独立收益」**：差值一律是同 seed 配对的条件差。

## 3. 口径限制（论文须如实声明）

1. `cost_polish_enabled=False` 会整段跳过 `post_cost_polish`，
   因此 **G=0 档的 B=1 只覆盖 `polish_assignment` 的 relocate/swap**，
   不含通道 B 的交付后跨机改派。交互项混有「算子可得性」差异，
   **不能解释成纯二阶交互**。
2. 若 `g0b1` 三本账显示零归属动作，说明 B 因子在 G=0 档未真正激活，
   此时交互项主要反映「G=1 档才拿得到通道 B」，不得写作「协同效应」。
3. 终点机巢 MCF 是**给定路径下的条件最优**（非全局最优）。
4. 冒烟 / mid 档结论**不可外推正式档**；正式档须单独跑批。
5. 单一场景（广州 3 机巢）、固定到达流、3 seed ⇒ df=2 效能极低；
   p 不显著须如实声明，也不得写成「无差异」。
6. 完成率 / 恒等式 / eliminating 为实验层硬断言；
   `independent_audit` 的几何重建重评仍是技术债
   （`RollingHorizon` 未暴露审计钩子）。

## 5. 结果

三档均 `RC=0`，正式档 12 次 × 约 5.5 min、总 1 h 4 min 35 s，
`FORMAL_RC=0`。产物 `results/<preset>/summary.json` / `summary.csv`，
日志 `results/formal_run.log`。**只有正式档可作结论依据**。

### 5.1 三档总览（再次验证「冒烟 / mid 不可外推正式档」）

| 档 | seed | 配置纯度 | 铁律全过 | f 交互项 | p | 航程交互项 (m) | p |
|---|---|---|---|---|---|---|---|
| smoke | 7 | True | True | −874.159 | 单 seed 不检验 | −8741.585 | 单 seed 不检验 |
| mid | 7,11,23 | True | True | −108.549 | 0.4270 | −1085.548 | 0.4270 |
| **formal** | **7,11,23** | **True** | **True** | **−27.062869** | **0.372719** | **−270.628667** | **0.372719** |

配置纯度：正式档逐 seed 只差 3 个预期字段
（`cost_polish_enabled` / `l3b_enabled` / `polish_moves`），
`unexpected_fields=[]`、`all_within_mode_identical=True`、
`unpaired_seeds=[]`、`invariant_failures=[]`。
冒烟档的交互项 −874、mid 档 −108.55、正式档 −27.06，**量级差 4~32 倍**；
方向一致但幅度完全不同，mid 档结论不可外推正式档这条铁律再次得到实测支持。

| 档 | f 之和 (7 / 11 / 23) | 总航程 km (7 / 11 / 23) | 完成率 | 按时率 | 硬违约 |
|---|---|---|---|---|---|

| `g0b1` | 4265.193 / 4210.994 / 3802.996 | 42.652 / 42.085 / 38.030 | 1.000 | 1 / 0.933 / 1 | 全 0 |

完成率、按时率、硬违约在四档间**逐位相同**；唯一的质量差异是航程与

### 5.3 正式档主效应 + 交互项（并列报告，禁写「独立收益」）

`f` 之和（越小越好；配对 t 检验，精确 Student t / 正则化不完全 β，df=2）：

| 效应 | 逐 seed (7/11/23) | 均值 | t | p 双尾 | 显著 |
|---|---|---|---|---|---|
| G@B0 | −2.220 / −40.396 / −64.426 | −35.680749 | −1.970 | 0.187638 | 否 |
| **G@B1** | −76.497 / −39.210 / −72.524 | **−62.743618** | −5.307 | **0.033718** | **是** |
| B@G0 | −144.159 / −1.186 / −145.562 | −96.969062 | −2.025 | 0.180185 | 否 |
| B@G1 | −218.436 / 0 / −153.660 | −124.031931 | −1.915 | 0.195601 | 否 |
| **交互** `(f00−f01)−(f10−f11)` | −74.277 / +1.186 / −8.098 | **−27.062869** | −1.139 | **0.372719** | **否** |

总航程 (m)：G@B0 −355.09 (p=0.188645)、**G@B1 −625.72 (p=0.034832)**、
B@G0 −969.69 (p=0.180185)、B@G1 −1240.32 (p=0.195601)、
交互 −270.63 (p=0.372719)。

**为何 f 与航程的交互 p 完全相同**：本实验完成率 / 硬违约 / 按时率四档相同，
迟到交互为 0，故 `Δf = 0.1·Δ航程 + 0.01·Δ迟到` 在交互项上退化为
`0.1·Δ航程` 的线性缩放（−270.628667 × 0.1 = −27.062867），t 同为
−1.139083。**这不是两条独立证据**，论文不得写成「f 与航程双双验证」。
非交互项因迟到差非零，p 略有不同（如 G@B0：0.187638 vs 0.188645）。

### 5.4 三本账（P3-b 口径，逐 seed 7/11/23）

| 台账 | `g0b0` | `g0b1` | `g1b0` | `g1b1` |
|---|---|---|---|---|
| `l3a_geometric_actions` | 0 / 0 / 0 | 0 / 0 / 0 | 4 / 4 / 5 | 7 / 3 / 6 |
| `l3b_relocate_actions` | 0 / 0 / 0 | 5 / 1 / 2 | 0 / 0 / 0 | 6 / 1 / 4 |
| `n_task_to_uav_changes` | 0 / 0 / 0 | 3 / 0 / 3 | 0 / 0 / 0 | 4 / 0 / 1 |
| `cost_polish_n_accepted` | 0 / 0 / 0 | 0 / 0 / 0 | 1 / 1 / 2 | 2 / 1 / 3 |
| `l3b_ungated_monotone_relocate` | 全 0 | 全 0 | 全 0 | 全 0 |

- G 因子确实激活（G=1 两档 L3a 非零），B 因子在 G=0 档**也**通过
  `polish_assignment` 的 relocate/swap 激活（`g0b1` L3b = 5/1/2 非零），
  所以 §3 第 2 条「B 在 G=0 未激活」的分支**未触发**。
- 但 §3 第 1 条口径限制**依然成立**：G=0 档整段跳过 `post_cost_polish`，
  `g0b1` 拿不到交付后通道 B；`cost_polish_n_accepted` 在 G=0 两档恒 0
  即是证据。交互项仍混有算子可得性差异，**不能解释成纯二阶交互、
  不能写成「协同效应」**。
- `l3b_ungated_monotone_relocate` 四档全 0 ⇒
  「`coverage_first` 单调 polish 的跨机 relocate 是否纳入总闸」在本场景
  **没有产生任何实测动作**，该待裁定项仍无证据，不得据本实验下结论。

### 5.5 与 exp07 两组正式档的交叉验证（逐位一致）

| 对照 | exp07 正式档 | exp08 正式档 | 一致 |
|---|---|---|---|
| L3b 关（`path` 档 / `g1b0`）f | 4407.132314 / 4171.783458 / 3884.132182 | 同左 | 逐位 |
| L3b 开（`on` 档 / `g1b1`）航程 m | 41886.966 / 41698.537 / 37304.721 | 同左 | 逐位 |
| B@G1 均值 / p | −124.031931 / 0.195601（§11.8 L3b 关→开） | −124.031931 / 0.195601 | 逐位 |

`g1b0` = exp07 的 `path` 档、`g1b1` = exp07 的 L3b `on` 档，
两个独立实验在**同一场景 / 同 seed / 同预算**下逐位复现，
说明 2×2 设计把两个单因素对照正确嵌进同一坐标系；
这也再次确认 §11.8 的「L3b 逐 seed 零反例但 p=0.1956 不显著」结论。

### 5.6 结论（论文可写 / 不可写）

可以写：

1. 四档完成率恒 1.000、硬违约恒 0、按时率逐位相同 ⇒
   **交付后精修只作用于成本，不改变任务完成与时间窗违约的判定**；
   这正是「受限交付精修」的职责边界。
2. 几何 + 归属同时开的生产档 `g1b1` 在 3 个 seed 上 f 与航程都最低，
   逐 seed 零反例；G 因子在 B=1 条件下的配对差是**唯一达到 0.05 显著**
   的效应（f −62.74 / 航程 −625.72 m，p=0.0337 / 0.0348）。
3. 归属因子的配对差（B@G1 −124.03、B@G0 −96.97）与交互项
   （−27.06）在 3 seed 下 **p 均 > 0.18，未达统计显著**；
   df=2 效能极低，须如实声明「未达显著」，**也不得写成「无差异」**。
4. 主效应必须在另一因子的固定水平下陈述（G@B0 与 G@B1 不同、
   B@G0 与 B@G1 不同），不能合并成一个「几何贡献」或「归属贡献」。

不可写：

- 「几何独立收益 −62.74」「归属独立收益 −124.03」——差值全是
  同 seed 配对的**条件差**，且交互项口径不纯；
- 「几何与归属存在协同效应」——交互项 p=0.372719 不显著，
  且混有 G=0 档算子可得性差异；
- 「f 与航程两个指标都验证了交互」——见 §5.3，是同一量的线性缩放；
- 把 mid 档的 −108.55 或冒烟档的 −874.16 当正式结论。
