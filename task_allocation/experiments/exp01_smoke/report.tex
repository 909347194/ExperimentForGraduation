\begin{abstract}
\noindent 本报告记录 exp01\_smoke 实验的设置与结果。实验在真实 DEM 地形（拉萨市城关区 ASTER GDEM 裁剪，约 30\,m 采样）上构建含 10 架无人机、6 个机巢、30 个带时间窗动态任务的场景，采用
\textbf{任务选择 + MUAS 求解} 的两阶段分配框架与滚动时域调度，任务分三个周期（20/5/5）到达，
以收敛早停终止。\textbf{（下述数值为 2026-10-19 旧口径快照，待重跑刷新，见文首口径切换说明。）}
结果显示：60 个任务全部完成（完成率 100\%），
\textbf{违约交付（废飞）0 次、淘汰 0 个、静态不可达 0 个}；
按时率 88.3\%（迟到 7 个，平均迟到 703\,s，最大 1505\,s），
奖励产出率 97.7\%、零奖励交付 0 个、有效完成率 100\%；
平均等待 700\,s，吞吐 7.5 任务/周期，总航程 1701.6\,km，累计奖励 324.23。
求解流程在 DMDE 收敛后施加解码后局部搜索（relocate/swap/position）收紧交付解
（三 seed 共接受 53 次严格改进移动，全部邻域收敛、零预算命中；机理与效果见 \S 2.5--2.6）。
作为方法变体，本文进一步实现 memetic M1\textbf{精英档案}——在 DE 循环内每 20 代对当代精英
施加同一局部搜索，使路由精修前移进搜索期：seed 42 按时率升至 91.7\%，
构成「无抛光 81.7\% $\to$ 收敛后抛光 88.3\% $\to$ memetic 91.7\%」的改进阶梯（\S 2.7）。
本报告同时明确各项指标的计算口径，特别是逐周期正确执行率与任务加权按时率的定义差异。
\end{abstract}

\subsection{实验目标与评价口径}

实验目标\textbf{不是}追求完成率，而是验证框架在\textbf{持续任务到达下尽可能多且正确地完成任务}
的长程执行能力。依据该目标，本实验采用以下核心指标口径：

\begin{itemize}
  \item \textbf{累计正确完成数}：真正交付执行的任务数（含迟到交付）；
  \item \textbf{违约交付（废飞）}：被判物理不可行、无人机已飞出航程且位置已更新、
        但任务解绑回池不计完成的事件。总航程下降若以此换来则为净亏损，须与吞吐同权报告；
  \item \textbf{淘汰}：deadline 已过仍在池中、被过期出池的任务数（机制缺陷信号，须为 0），
        对物理可行任务是兜底失灵的信号，应趋近于 0；
  \item \textbf{静态不可达}：所有机巢往返航程均超过满电可及范围的任务
        （过于偏远，属物理约束，是唯一合法的未完成原因），入池时一次性判定出池；
  \item \textbf{吞吐}：累计完成任务数 / 实际运行周期数；
  \item \textbf{每周期正确执行率}与\textbf{按时率}：衡量执行质量（口径见 \S 2.3）。
\end{itemize}

\subsection{指标体系 v2（2026-10-22）与本快照的口径映射}

论文主表口径按「可完成的最终都应完成，只是或早或晚；在此前提下控成本与时效」
重标定（v2）。三层指标定义如下：

\begin{itemize}
  \item \textbf{最终完成率} $\eta_{\mathrm{final}}$ = 最终交付数 /（到达数 $-$ 物理不可达数）：
        分母排除物理不可达（问题固有，不归算法能力）；\textbf{淘汰是机制缺陷信号、须为 0，不单列合法失败类}
        （可做却永久丢失 $=$ 失败，淘汰率单列正因如此）；
  \item \textbf{按时率} = 最终交付中 deadline 前完成的比例（迟到交付计完成、
        不计按时），另报平均/最大迟到；
  \item \textbf{单位完成航程} = 总航程（含返航）/ 最终完成数，与总航程并列，
        避免成本口径被完成数绑架；
  \item \textbf{淘汰数} = 机制缺陷计数（须为 0），淘汰率 = 淘汰数 /（到达 $-$ 不可达）；
        \textbf{物理不可达数/率}单独列，不进失败分母；
  \item \textbf{过程指标}：名额利用率 $\sum n_{\mathrm{sel}}^{\mathrm{used}} /
        \sum n_{\mathrm{sel}}^{\mathrm{cap}}$、平均/峰值积压、跨周期推迟量
        （交付周期 $>$ 到达周期，即「或早或晚」）、平均等待、求解耗时；
  \item \textbf{方法诊断指标}：$n_{\mathrm{skip}}$（voluntary\_skip，覆盖门禁下应为 0）、
        $S$ 内覆盖率、一阶 shortfall、废飞、硬违约次数——支撑「覆盖是约束、
        成本是目标」，不替代主表。
\end{itemize}

本快照（2026-10-19，三 seed）在 v2 口径下\textbf{数值不变}：不可达 $=$ 淘汰 $=0$
$\Rightarrow$ $\eta_{\mathrm{final}}$ 与旧完成率同值（60/60）；废飞 $=0\Rightarrow$
按时率两口径同值（如 seed 42 均为 88.3\%）。v2 新增可报告列：单位完成航程
（seed 42/43/44 = 28.36 / 29.21 / 27.08\,km/完成，均值 28.22），已入表~\ref{tab:seeds}。

\subsection{实验定位与证据边界}

本实验是框架的\textbf{冒烟与正确性验证台}（smoke \& correctness bench），
而不是性能主实验。它回答「闭环按理论口径执行了吗」，
不回答「方法比谁好、长程能撑多久」——后者由后续实验分工承担
（证据链见表~\ref{tab:evidence}）。三项职责：

\begin{itemize}
  \item \textbf{闭环正确性}：任务选择—MUAS 求解—修复链—执行—状态更新全链路按协议
        运转，由 \fname{audit\_correctness.py} 的 23 项不变量自动对账门禁保障
        （终局守恒、完成唯一、闸门语义、时间语义、奖励守恒、航程物理、
        适应度可复算等；每次运行末尾自动执行，FAIL 即阻断）；
  \item \textbf{口径标定台}：四层准字典序适应度、迟到折减窗 $W=1800$\,s、
        「迟到不是废飞」与「未完成只有物理约束被违反」等关键口径在此标定，
        消融细节见 \fname{ABLATION\_fitness\_tiers\_2026-10-18.md}；
  \item \textbf{回归基线}：后续机制修改以本实验的逐位一致作为无回归证据
        （消融 A1 与 A0 逐位一致即此类用法）。
\end{itemize}

据此，本报告\textbf{可以}声称：实现与理论口径一致（23 项检查全部通过或为
已知低危 WARN）、关键指标在 3 个随机种子下稳健（表~\ref{tab:seeds}）、
上述参数标定有实验依据。本报告\textbf{不能}声称：

\begin{itemize}
  \item \textbf{方法优于任何基线}——对比方法尚未接入统一评价（属 exp05 职责；
        未实现的算法不得进入正式结果表）；
  \item \textbf{长程吞吐能力}——本实验任务集中在第 1--3 周期到达（20/5/5）、
        第 4 周期起无新到达，靠收敛早停终止（约 7 周期）；长程协议（Poisson 到达、多周期）下的证据
        应由独立的滚动实验承担；
  \item \textbf{选择层规模压缩收益}——本实验机多任务少（10 架 / 30 任务），
        $n_{\mathrm{cand}}$ 截断从未触发，该机制属 exp02 职责；
  \item \textbf{100\% 完成率即方法有效}——完成率受场景容量与航程约束影响
        （旧口径下容量宽松、完成率饱和；城关区新口径 20\,km 航程下存在真几何不可达
        任务，完成率不再饱和），不区分方法好坏，性能对照须在统一基线下进行。
\end{itemize}

\subsection{滚动时域与两阶段求解流程}

仿真按滚动时域推进，每周期执行一次完整的分配—执行循环：

\begin{enumerate}
  \item \textbf{任务选择（selection）}：按「优先级 $\to$ 可行性 $\to$ 边际收益」三级顺序，
        从当前任务池中选出本周期参与分配的任务集，并挑出可出动的无人机；
  \item \textbf{MUAS 求解（muas）}：以 DMDE（离散多目标差分进化）搜索
        \textbf{无人机归属 + 访问顺序}；\textbf{终点机巢不进编码}，
        而由内层最小费用流在容量约束下精确求解后解码，返航代价计入目标；
  \item \textbf{修复链}：对求解结果依次执行合并、剔除、航程修复与终点机巢选择，
        迭代至定点收敛，再执行覆盖补全与时间窗重排；
  \item \textbf{解码后局部搜索（polish）}：DMDE 收敛后，对交付解在解空间上直接施加
        \textbf{relocate / swap / 插入位}三类移动——每个候选解经过与搜索期\textbf{同一}修复链
        重建后，仅当适应度严格改进才接受，迭代至邻域收敛（轮数/评估数预算内）。
        该步骤直接作用于解空间，对冲收敛曲线早平所暴露的次级目标优化动力不足
        （机理见 \S 2.6，收益见表~\ref{tab:polish}）；
        方法变体（memetic M1）进一步把同一局部搜索前移进 DE 循环内维护精英档案
        （\S 2.7，默认关闭、不影响本基线）；
  \item \textbf{执行与状态更新}：无人机按航次起飞，消耗航程、更新位置，周期末在机巢充电。
\end{enumerate}

DMDE 参数：种群规模 50，迭代代数 100（论文主口径，500 代另作敏感性对照）。
适应度采用\textbf{四层准字典序}标量化（物理违约 $\to$ 交付收益 $\to$ 迟到 $\to$ 航程/负载）：
\[
  f(s) = W_{\mathrm{hard}}\cdot n_{\mathrm{hard}}(s)
       + w_{\mathrm{exc}}\cdot \mathrm{excess}(s)
       - m\cdot F_1^{\mathrm{eff}}(s)
       + w_{\mathrm{late}}\cdot L_{\mathrm{tot}}(s)
       + \lambda\cdot \mathrm{path}(s)
       + w_{\mathrm{time}}\cdot F_3(s),
\]
其中 $n_{\mathrm{hard}}$ 为物理硬违约次数（航程/续航/终点机巢/容量/结构类），
$W_{\mathrm{hard}}=\kappa\cdot m\cdot R_{\mathrm{pool}}$（$\kappa=10$，按当周期候选任务奖励和自动推导）
保证\textbf{任何一次物理违约压倒任意交付收益}，杜绝「纸面可行、执行弹回」的幽灵收益入选；
$F_1^{\mathrm{eff}}$ 为按迟到折减后的有效交付收益；
$L_{\mathrm{tot}}$ 为迟到秒数合计（软约束，$w_{\mathrm{late}}=0.01/\mathrm{s}$，
只与航程同台竞争、永不与任务数竞争）；
$\lambda = 1.0\times10^{-4}$ 收益当量/米。
早停条件：任务池规模连续 4 个周期不变即判定收敛。

\subsection{约束口径与完成判定协议}

\begin{itemize}
  \item \textbf{航程约束}：$\text{往返航程} \le \text{margin}\times\text{剩余航程}$，
        $\text{margin}=1.0$（满电物理上限），与完成闸门同口径；
  \item \textbf{时间窗}：预筛阶段\textbf{不}以时间窗作为参选资格，
        迟到由适应度定价而非直接拒绝；
  \item \textbf{约束分层}：物理约束（航程/续航/终点机巢/机巢容量/结构类）为\textbf{硬违约}，
        时间窗迟到为\textbf{软违约}——二者进入适应度的不同层（见 \S 1.5），
        可行性判定只认硬违约，与执行闸门的弹回标签口径一致；
  \item \textbf{完成判定}：仅当任务被判\textbf{物理不可行}（硬违约）时才弹回任务池、不计完成；
        \textbf{迟到不算废飞}——迟到交付计入完成，奖励按
        \[
          \text{eff} = R \times \max\!\left(0,\; 1 - \frac{L}{W}\right)
        \]
        折减，其中 $L$ 为迟到时长，$W=\text{late\_reward\_decay\_seconds}=1800$\,s。
        $W$ 的标定依据：本实验迟到任务的最大迟到为 1504.9\,s，
        $W=1800$\,s 时全部迟到任务保留部分奖励（7 个迟到任务平均保留 60.9\%、
        最低 16.4\%）、零奖励交付为 0，
        且迟到达到 $W$ 才等价于丢失整个任务，保持按时压力。
\end{itemize}

\subsection{指标口径说明（重要）}
\label{sec:caliber}

本实验涉及三个容易混淆的「率」，口径互不相同，引用时必须同时说明统计窗口：

\begin{itemize}
  \item \textbf{每周期正确执行率}（\texttt{correct\_exec\_rate} $=0.883$）是
        \emph{逐周期比率的均值}，且\textbf{只对有作业的周期平均}：每周期计算
        \[
          r_c = \frac{\text{当周期按时出动}}{\text{当周期出动}},
        \]
        再对 3 个有作业周期取算术平均：
        \[
          \frac{0.900+0.850+0.900}{3}=0.883 .
        \]
        空转周期（周期 4--8，出动为 0）\emph{不}入均值——早期口径把它们记 0
        再平均，5 个零值会把 0.883 摊薄成 0.331，与按时率矛盾，该口径已修正；
        该指标对\textbf{单任务周期}天然敏感（seed 44 周期 5--7 各仅 1 个任务且迟到，
        逐周期计 0，见表~\ref{tab:seeds} 注），跨 seed 比较应以任务级按时率为准；
  \item \textbf{按时率}（\texttt{on\_time\_rate} $=0.883$）是\emph{按任务加权}的
        总体比例：$(60-7-0)/60=0.883$；
  \item \textbf{周期级可行率}（\texttt{cycle\_feasible\_rate} $=1.000$）是
        \texttt{muas.feasible} 为真的周期占比。注意其语义随约束分层更新：
        可行 = \textbf{零物理硬违约}（航程/续航/终点机巢/容量/结构），
        迟到（软违约）\emph{不}再判不可行，与执行闸门「\texttt{range\_uav\_*} 弹回、
        \texttt{tw\_task} 不弹回」的标签口径一致。因此该指标衡量的是
        「求解器是否交出物理可执行的解」，而非「是否全部按时」。
\end{itemize}

因此，报告中引用该指标时必须同时说明统计窗口。
\textbf{本实验的短周期特性（仅 3 个有效作业周期）也限制了其作为长程吞吐证据的强度}，
更长程的证据应由周期性到达协议（Poisson）下的独立实验提供。

\textbf{适应度记账口径}：收敛曲线（\texttt{cost\_history}）与
\texttt{best\_fitness} 为\textbf{搜索期}口径——Lamarckian 基因回写只改写起始基因
通道、巡游基因保留未修复原值（有意的保守设计，避免基因层增删破坏
「每任务恰出现一次」不变式），回写后基因解码重建的交付解与当时被评价的解在
任务集 / 访问顺序 / ETA 上可不同，两者适应度本不可比。交付解自身的适应度与
成分（有效奖励、迟到秒数、航程、硬违约次数）另册落盘，审计 N 项用权重快照
独立重算对账（3 个 seed 的全部活跃周期均通过）。本实验中交付解适应度在全部
活跃周期不差于曲线终点（$+0\sim+13.7\%$），即回写与修复链只改进不劣化；
引用收敛曲线时应说明其为搜索期口径，交付质量以汇总指标为准。

\subsection{结果分析}

\begin{enumerate}
  \item \textbf{违约交付归零}。本实验 0 次废飞、0 淘汰、0 不可达，
        60 个任务全部真正交付。这表明修复链（航程修复、覆盖补全、终点机巢选择）
        与完成闸门之间已形成闭环，不再出现「无人机已飞、任务回池」的净亏损。
        该指标曾因重排阶段漏算返航腿而出现 16 次弹回，修复后归零。
  \item \textbf{迟到集中在前期}。7 个迟到中 5 个发生在周期 1--2
        （初始 30 个任务集中到达，10 架机需在首周期消化 20 个），
        周期 3 余 2 个，周期 4 起任务池已空。平均迟到 703\,s，
        最大 1505\,s（T24，奖励保留 16.4\%），均小于折减容忍 $W=1800$\,s——
        没有任何任务因迟到丢失全部奖励，零奖励交付为 0，奖励产出率 97.7\%。
  \item \textbf{迟到容忍的重新标定消除了零奖励交付}。早期口径 $W=600$\,s 下
        （无抛光口径，消融细节见 \texttt{ABLATION\_fitness\_tiers\_2026-10-18.md}），
        本实验有 7 个迟到任务的有效奖励被折减至 0（迟到实质等同于废飞），
        按时率 80.0\%、奖励产出率 88.0\%、总奖励 291.90。
        将 $W$ 重标定为 1800\,s 后：零奖励交付 $7\to 0$、奖励产出率
        $88.0\%\to 94.4\%$、按时率 $80.0\%\to 81.7\%$、总航程 $-2.2\%$，
        完成数、废飞、淘汰均不变；在此基础上叠加解码后局部搜索，
        基线进一步变为按时率 88.3\%、奖励产出率 97.7\%（完整改进阶梯见 \S 2.7）。
        这与「迟到可以接受、但最好不迟到」的目标口径一致：迟到仍计完成、
        仍付部分奖励，但迟到越深保留越少。
  \item \textbf{机群利用充分}。10 架无人机全部参与，三个作业周期分别出动
        7 / 9 / 9 个航次，平均每航次 2.4 个任务；周期 4 起任务池已空、停机。
  \item \textbf{代价与吞吐}。总航程 1701.6\,km，吞吐 7.5 任务/周期
        （若仅按有效作业周期计为 20.0 任务/周期），平均等待 700\,s。
  \item \textbf{解码后局部搜索进一步收紧交付解}（现为求解流程第 4 步，基线已含）。
        DMDE 收敛曲线早平（\S 2.6 机理）
        使次级目标（路径 / 迟到）优化动力不足；polish 在交付解上直接施加
        relocate / swap / position 三类移动，每个候选过同一修复链、仅严格改进才接受。
        三 seed 共接受 53 次移动（51 relocate + 2 swap + 0 position），全部邻域收敛、
        零预算命中，累计严格改进 $8.30\times10^6$ 适应度单位；
        position 移动被修复链 EDD 重排中和故 0 次接受——印证「插入位」在闭环中
        由重排自动处理。增益集中在周期 1--2（初始任务批量到达），
        relocate 将任务从较远 UAV 改派到更近机位 / 槽位，是 polish 主力
        （seed42 周期 1 单周期增益 $1.18\times10^6$）。该步骤使交付解在 DMDE 收敛后
        仍被压低，且不引入任何物理违约（审计 N2 仍全通过，详见 \S 2.5）；
        把同一搜索前移进 DE 循环的 memetic 变体见 \S 2.7。
\end{enumerate}

\subsection{收敛特性与 DMDE 早收敛机理}
\label{sec:convergence}

本实验 DMDE 收敛曲线在前若干代即快速下降并早平（逐周期收敛曲线见
图~\ref{fig:anim} 右栏），
表面看「收敛过快」，本质是其适应度结构使次级目标在已锁定的交付结构下
几乎无梯度。五点机理：

\begin{enumerate}
  \item \textbf{big-M 阶梯函数主导}。物理违约项 $W_{\mathrm{hard}}\cdot n_{\mathrm{hard}}$
        的步长约 $2.8\times10^5$ 适应度单位（多锁住一个任务的交付收益），
        而一条巡游路径优化仅约 $1.7\times10^2$ 单位——一旦交付结构
        （哪些任务被完成、由谁完成）锁定，子目标改进相对步长可忽略，曲线即平台化；
  \item \textbf{SRP 编码预抢奖励}。离散层哨兵编码在首轮即按行序最近邻抢任务并
        锁定归属，约 96\% 奖励在第一代即到手，后续搜索只剩毫厘改进空间；
  \item \textbf{Lamarckian 回写冻结归属}。精英起始基因被回写并逐代复现，
        闲置槽位成为「死维度」，差分变异难以翻盘重分配；
  \item \textbf{差分算子对翻盘收益「盲」}。一次改派能省下的路径约 27.9\,km，
        折算适应度仅 $\lambda\times27.9\times10^3\approx 2.8$ 单位，
        相对 $2.8\times10^5$ 的步长与 $10^7$ 量级的目标值几乎不可见，
        变异方向不朝它收敛；
  \item \textbf{尾部毫厘震荡}。锁定后各代目标值极差仅约 0.008\%，
        早停（连续 4 周期池不变）或 100 代即达平台。
\end{enumerate}

这五点决定了 DMDE 适合「找可行交付结构」而非「精修路径」——
后者正是解码后局部搜索（\S 2.5）的职责：polish 在已锁定的交付结构上做
解空间级 relocate / swap，每条改进过修复链且严格接受，把 DMDE 留下的次级目标
空间继续压低，且不破坏已锁定的合法交付。二者分工：
\textbf{DMDE 负责「对」（可行交付结构），polish 负责「好」（次级目标精修）}。
memetic 变体（\S 2.7）进一步把「好」的求精前移进 DE 循环，
使次级目标在搜索期内即被持续压低。

\subsection{memetic 变体：搜索期内的路由增强（M1 精英档案）}
\label{sec:memetic}

\S 2.6 的五点机理表明：DMDE 在搜索期内对路由级改进近乎「盲」，
次级目标空间全部留给收敛后的 polish 收割。一个自然的加强是把同一局部搜索
\textbf{前移进 DE 循环}：每 $K$ 代对当代精英施加一次 polish，
维护一个 best-polished \textbf{精英档案}，使「路由在降」在搜索期内即持续发生。
本报告实现该变体（记为 memetic M1），作为 exp01 的方法变体单独呈现
（开关 \texttt{polish\_in\_loop}，默认关闭，基线行为逐位不受影响）。

\textbf{实现与安全语义}。实现仅利用 DMDE 代际循环末尾的通用钩子
（\texttt{gen\_callback}），不触碰基因型：每 $K=20$ 代对当代精英跑一次
\textbf{从紧预算}的 polish（6 轮 / 500 评估封顶，控制单周期耗时），
档案记录历代最优的（assignment, fitness）；交付解取
「收敛后 polish」与「档案最优」的更优者。钩子不产生随机数、不改写群体，
故同种子下开 / 关开关的 DMDE 搜索轨迹\textbf{逐位相同}
（回归测试 \fname{test\_memetic\_inloop.py} 锁死该不变量），
搜索期记账口径（\S 2.3）不受污染；档案候选与收敛后 polish 走同一修复链，
同样不可能产出「纸面可行、执行弹回」的幽灵解。

\subsection{讨论与展望}

\begin{enumerate}
  \item \textbf{M1 的边界与 M2（Lamarckian 反射写回）}。M1 的精英档案不回流群体：
        路由改进参与终局择优，但不改变 DE 后续的结构搜索。要让路由改进真正
        参与演化（memetic 的完整形态），需要把 polished assignment \textbf{反射}
        回 SRP 基因型；而哨兵编码未必能表示任意 polished assignment
        （硬写回可能 lossy，解码结果与档案解不一致）。这构成后续工作 M2：
        要么扩展编码保证可反射性，要么对不可反射的档案解启用保护性变异。
        本报告刻意不碰基因型，以「零反射风险」换取 M1 的可审计性。
  \item \textbf{次目标梯度的显式标定}。\S 2.6 指出路由梯度被自动大-M 饿到
        近乎为零是从未单独标定的副作用。可将「大-M 高度 / 次目标梯度可见性」
        列为 exp04（关键设计逐因素消融）的一个维度：在保持
        「任何硬违约压倒任意交付收益」不变式的前提下，标定路由改进在搜索期内
        可见所需的最小 $\lambda$ / $\kappa$ 组合。
  \item \textbf{变体定位}。memetic M1 属 L2（设计有效性）证据的雏形：
        它证明「把解码后局部搜索前移进搜索期」在本场景下严格占优基线；
        其在长程协议（Poisson 到达）与 $|T_t|\gg K$ 场景下的收益，
        应由相应滚动实验与 exp02 承担，本报告不外推。
\end{enumerate}
