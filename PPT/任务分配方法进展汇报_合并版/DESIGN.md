## 口径纪律（合并时消除的冲突）

旧「进展汇报」版含 `四层准字典序` / `F3 = max_u T_u` / `−m·F1` / `big-M 加权` /
`覆盖优先装载承担完成语义` / `Lamarckian 回写默认 M1` 等历史口径，全部按当前代码改写：

| 旧表述 | 当前代码事实 |
|---|---|
| 四层准字典序 / + w_time·F3 | `scalar_fitness` 单一加权标量 f；F3 已整体移除 |
| big-M 形式 `−m·F1` | 搜索用 f 不含 `−m·F1`；`big_m` 仅作 W_hard / W_skip 推导基数 |
| 覆盖优先装载默认、门禁退居事后校验 | `coverage_first=False` → `_complete_coverage` 单趟；EDD 不动点为对照档 |
| Lamarckian 回写默认开（M1 / M2-1） | `repair_replacement=0` 纯 Baldwin；回写为可选连续比例对照档 |
| 贪婪选择 | `CompareSpec` 默认 `penalty`；deb / epsilon / lagaros 为对照档 |
| 最小费用流（无边界） | 默认 auto 走 MCF；`projection_only` / `end_nest_l1_mode=nearest` 可切投影对照 |
