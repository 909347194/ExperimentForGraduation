# STORY.md — 任务分配方法与第二阶段原理讲解（2026-11-10 新建）

> **用途**：一份把「任务分配问题 → 整体方法 → 第二阶段的求解过程与设计原理」串起来的方法讲解 deck，
> 19 页，面向导师 / 组会。与既有两份 deck 的分工：
> - `UAV协同任务分配方法-进展汇报`（18 页）：背景、意义、现状、进展，方法只作定位陈述；
> - `第二阶段原理讲解`（12 页）：只拆第二阶段六环节，缺任务分配问题与整体方法的铺垫；
> - **本 deck**：补上问题定义与两阶段框架，并重点展开第二阶段「过程（怎么跑）+ 原理（为什么这么排）」。
>
> **口径纪律**：只讲方法，不写实验结论、不写「优于某方法」的对比宣称；公式、模块名、口径
> 唯一来源为 `task_allocation/Chapter3_README.md`（当前实现）与 `task_allocation/methods/`。
> **相对旧 deck 的口径更正**（重要）：当前代码已移除「以交付收益最大化为第一目标的字典序」
> 与 big-M 加权形式，`lexicographic*` 等开关名是历史命名；`F3` 已整体移除。当前主口径为
> **覆盖门禁口径下的单一加权标量**：
> `f = W_hard·n_hard + w_exc·E_m + W_skip·n_skip + w_late·L_tot + λ·C_path`，
> 合法解上退化为 `w_late·L_tot + λ·C_path`；`F1 = Σ R_j·y_j` 只作事后指标，不进搜索适应度。
> 旧 deck 中的「四层准字典序 / −m·F1 / F3 = max T_u」表述不再使用。
