# DESIGN.md — 任务分配方法与第二阶段原理讲解

## 全局视觉约定

**① 画布与安全区**：1280×720；顶条 0–72（A3 深蓝）；内容区 x 60–1220（1160 宽）、y 88–652（564 高）；
页脚 y 670–700（左单位 14px 灰 / 右页码 14px 主蓝）。封面、目录、章节扉页、结束页可省略顶条与页脚。
所有内容元素落在安全区内，顶条 / 页脚为全宽出血装饰。

**② 配色**：主色 `#1E4FA8`（顶条、编号、强调）；辅色 `#E8EFF8` / `#F0F5FC` / `#3D7BD9`（卡底、描边）；
强调色 `#D9534F`（仅 ≤3% 重点警示）；底色 `#FFFFFF` / `#F7F9FC`；
正文 `#1A2230` / 次要 `#4A5568` / 辅助 `#8B97A8`；线框 `#D6DCE5`。
面积纪律：蓝族 35–55%、白底 30–55%、红黄 ≤5%、金色 0。C 区禁深色实底。

**③ 字体**：中文 Microsoft YaHei（思源黑体系）；封面英文长标题 Times New Roman。
字号阶梯：封面中文主标 56 / 英文 22 / 章节大数字 150 / 页面主标 30–34 / 卡内标题 24–26 /
正文 22–24 / 表格 20–22 / 注解与页脚 14–16。同页文字样式 ≤4 种。

**④ 视觉母题**：页标题下的 1px 贯通细线只在主标题处出现一次（本 deck 用顶条下的浅蓝分隔带承担），
章节编号统一「深蓝方块 + 两位数字」，全篇不新增装饰母题。

**⑤ 配图**：全篇 L1 视觉统一为流程 / 结构矢量示意，由原生 Box + Text + 细线绘制，无位图、无生成图。
 Hero 页的流程图为 anchor，其余页的机制图为 evidence。
