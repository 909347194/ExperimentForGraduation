## 一、先想清楚：这次汇报要拿到什么

向导师汇报最忌"流水账念工作"。**带着三个必须拍板的决策去**，汇报结构为它们服务：

| 必须拍板 | 为什么重要 |
|---|---|
| ① 目标期刊：《系统工程与电子技术》还是《信息与控制》 | 决定格式（图表题中英/中文）、投稿载体（Word 双栏）、流程（保密审查）与时间线 |
| ② 期刊论文三条贡献点是否定稿认可 | 引言已按三条写完，后续所有章节与实验都对它负责 |
| ③ 时间表：投稿节点怎么定 | 决定实验批次（P0/P1）与论文写作的并行节奏 |

另有 3 件**建议征询**（导师给方向即可，不占决策时间）：M2-1 写正文还是留展望、
时序链口径声明还是实现、学位论文主辅篇幅比例。P15 请示页按"3 拍板 + 3 征询"分组呈现，
与 P2 的预告严格一致。

叙事主线一句话：**问题（持续任务流下为什么难）→ 思路（选择—分配—滚动三层分解）→
证据（真实双场景数据 + 已完成的审计与 A/B）→ 计划（P0 实验批次 + 论文写作）→ 请示**。

**时长配额**（20 分钟，与页面分章严格对齐）：

| 段 | 页面 | 配额 |
|---|---|---|
| 背景与缺口 | P3–P4 | 4 min |
| 研究内容与问题定义 | P5–P6 | 3 min |
| 方法（三层） | P7–P10 | 6 min |
| 实验与论文进展 | P11–P13 | 4 min |
| 计划与请示 | P14–P15 | 3 min |

方法细节如果被追问，亮出方法专版 PPT 备用，不在本 deck 展开。

## 二、PPT 大纲（16 页）

- 主标：多无人机智能调度中的任务分配与航迹规划方法研究（学位论文题目）
- 副标：阶段进展汇报——滚动时域下多机巢多无人机选择性任务分配
- 汇报人 / 导师 / 日期
- 视觉：广域巡检场景示意（DEM + 机巢 + 航次），沿用方法专版视觉语言

### P2 汇报提纲（catalog）

五段式：研究背景与缺口 / 研究内容与方法 / 实验与论文进展 / 下一步计划 / 请示与讨论。
页脚标注"本次需要导师拍板 3 件事、征询 3 件事"。
**开场白设计（30 秒，站定先说）**："方法设计已经闭环、实验基建过半、论文引言成稿；
今天想占用老师 20 分钟，重点请老师定三件事：投哪个刊、三条贡献点认不认、时间表怎么排。"

### P3 研究背景与意义

- 场景：广域巡检、流域勘察、低空物流等**持续性作业**（≠ 任务批量下达）
- 三个特征：任务陆续到达、机巢分散、三维地形代价
- 一句话定位：任务分配是连接任务需求、飞行可行性与机队资源管理的关键决策环节
- 讲法：用杆塔巡检数字举例（万基杆塔 vs 单机日 15~50 基 → 供不应求）

### P4 研究现状与缺口

- 三层综述压缩版：范式（事件驱动重分配 → 连续性差）/ 方法（四类 → 接纳非决策变量、
  单机巢起飞、几何邻近代价）/ 验证（灾害批量场景 → 联合建模不足）
- 四个缺口（与贡献一一对应）：持续到达 / 选择性接纳 / 分散机巢 / 状态继承
- 视觉：缺口-贡献映射图（左四缺口 → 右三贡献箭头）

### P5 研究内容总览（双线定位）

- 学位论文线（6 章）：① 绪论 ② 相关理论与技术 ③ 动态滚动的选择性多机巢任务分配（主）
  ④ 顾及风险时空异质性的航迹规划（辅）⑤ 系统实现与应用验证 ⑥ 总结与展望
- 期刊论文线（5 节）：《滚动时域下多机巢多无人机选择性任务分配方法》——
  问题模型 / 三层方法 / 实验 / 结论；即学位论文第 3 章的期刊化
- 当前阶段重心：任务分配；航迹规划可见性图方法已落地（path_planning 的 exp02_vg 验证过）
- 讲法：只做定位陈述，**为 P15 的篇幅问题埋钩子**，此处不展开讨论、不请导师表态

### P6 问题定义

- 单周期四决策：y_j（接纳与否）× x_uj（指派）× π_u（访问顺序）× z_ub（终点机巢）
- 硬约束：航程 / 飞行时间 / 时序 / 同步 / 机巢容量与可用性 / 终点可达性；
  软约束：迟到计价不淘汰
- 目标：字典序——覆盖优先，覆盖等价再压含返航的三维航程
- **映射显式**：y → P8 选择机制；x/π/z → P9 分配与终点巢；跨周期 → P10 滚动闭环
- 讲法：强调"选择性"与"异巢起降联合精确决策"是与既有问题定义的两个分野

### P7 方法总览：三层分解（hero 页）

- 流程图：任务池 → ① 选择（缩空间）→ ② 分配（DMDE + 终点巢 MCF）→ ③ 滚动（闭环回池）
- 核心主张：快速任务选择缩空间 + 精细组合优化 + 滚动状态继承
- 三卡对应三条贡献（本页是全场"地图"，后面方法页都回指它）

### P8 方法①：选择性任务接纳（对应 y 决策）

- 时变能力上界 cap(t)（可起飞机队剩余航程 / 粗代价中位数；充电机不计幻影容量）
- 边际收益—代价比纳入 + 等待时长软加权 + 超时/临期强制纳入（防饥饿）
- 迟到软计价：晚到仍计完成，按迟到折减
- 讲法：一句话点题——"是否接纳"与"如何分配"并列成显式决策

### P9 方法②：多机巢协同分配与终点机巢求解（对应 x/π/z 决策）

- 统一编码（起始基因 + 巡游基因；终点巢剥离）+ 离散映射 DE（DMDE，与 Zhao 2017 同族改进）
- 解码修复链（合并 → 航程/时间修复 → 覆盖补全 → 重排 → 装配）
- 终点机巢：容量约束下最小费用流**联合精确求解**（给定路线下条件最优），返航代价入完整航程
- 覆盖门禁适应度："完成是约束、成本是目标"的构造性实现

### P10 方法③：滚动闭环与状态继承（对应跨周期）

- 周期时序：到达入池 → 选择 → 分配 → 出动 → 反馈更新
- 完成闸门：物理不可行回池（完成率不说谎），迟到照常完成
- 状态回贯：cap(t) 与选择优先级吃进跨周期状态；事件（故障/紧急任务/机巢变化）触发重规划
- 讲法：对比事件驱动"从零重建"——增量重解保连续性、降重规划规模

### P11 实验进展（已完成）

- **双场景真实地理数据**：广州城市（5 类 20670 栋建筑包络 + 3 机巢）/ 拉萨城关（30 m DEM + 6 机巢），
  只改配置即可切换
- **exp01 冒烟与审计**：3 seed 正式口径，正确性审计 26/26 通过
- **M2-1 段内巡游序回写 A/B**：三档配对比较完成，结论=情境性增益（截止压力实例最大 ≈20%
  路径成本下降，否则中性），默认关
- **⚠️ 证据边界（主动声明，先于导师发问）**：以上是**正确性与基建**证据；
  性能主表（基线对比/消融）**尚未产出**——见 P12 计划，预计 P0 批次 2~3 周
- 讲法：数字说话（审计 26/26、三档 A/B）；先亮边界再讲成绩，防"误以为有结果"的后期反噬

## 三、汇报注意事项（怎么讲）

1. **先结论后细节**：每章第一句就是判断（"方法已经闭环，实验还差主表批次"），
   细节按导师反应展开；不背诵 PPT 文字。
2. **数字先行**：审计 26/26、M2-1 三档 A/B、20670 栋建筑、30 m DEM——
   具体数字比形容词可信十倍。
3. **诚实报缺口 + 主动亮边界**：exp03/exp04 未实现、exp05/06 未跑完、性能主表没有——
   直说并给批次计划；导师最忌"都挺好"然后中期暴雷。
4. **准备被追问的问题**（附参考答法）：
   - 性能数据什么时候有？→ P0 批次 2~3 周出主表；本次先给口径、基线框架与审计背书。
   - 为什么用 DMDE 不用强化学习？→ 样本效率、可解释、硬约束可显式注入；
     RL 在综述谱系里有位置，作对比方向而非主方法。
   - 和 Chen 2025（多机巢杆塔巡检）、Han 2025（滚动时域 APSO）区别？→
     它们分别是"多机巢但非滚动"与"滚动但全分配+单功能站点"；本文补
     选择性接纳 + 终点机巢联合决策 + 状态继承三件事。
   - 三维代价会不会太慢？→ 惰性缓存 + 垂直切面预估；单周期求解时间有规模扫描（exp02）背书。
   - 最大飞行时间与航程约束重复？→ 对称但独立（续航绑定档单独验证，a2d6ecf）。
5. **材料提前发**：PPT 前一天发导师；附 1 页"3 拍板 + 3 征询"清单，讨论效率翻倍。
6. **会后**：把导师拍板结果落进 `task_allocation/docs/` 与论文审查文档（本次汇报本身
   也是口径来源）。
