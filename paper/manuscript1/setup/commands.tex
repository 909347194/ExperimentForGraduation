% ---------- 封面/题名页标签对齐 ----------
% 将两字标签（如“学号”“姓名”）撑满四字宽，与“学科专业”等四字标签冒号对齐。
% 原理：xeCJK 会在相邻汉字间插入弹性 glue，普通 \makebox[4em][s] 因此报
% "Underfull \hbox (badness 10000)"。改用数学模式排版：\vcenter{\hbox to 4em}
% 提供刚性水平盒（盒内无基线 glue），\hbox 承载文字并临时关闭 CJKspace，
% \hss...\hss 两端居中撑满 4em。已在 TeX Live xelatex 实测零警告、零错误。
\newcommand{\labelfour}[1]{%
  \ensuremath{\vcenter{\hbox to 4em{\hss
    \hbox{{\xeCJKsetup{CJKspace=false}#1}}
    \hss}}}%
}
% ---------- 封面/题名页冒号与内容间隔 ----------
% 学位论文模板中冒号后接内容的标准间隔为一个全角空格（约等于汉字宽）；
% \zhqspace 定义为 1em，随字号自动缩放（三号=16磅、小四=12磅）。
\newcommand{\zhqspace}{\hspace{1em}}
