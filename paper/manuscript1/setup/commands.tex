% ---------- 封面/题名页标签对齐 ----------
% 还原 Word 式样：所有标签（学号/姓名/学科专业/指导教师/培养单位，无论 2 字或 4 字）
% 都装进【同一固定宽度的分散对齐单元格】。Word 实测：4 字标签字距约 0.5em，
% 2 字标签「姓名」被拉开成一大段空隙（约 3.5em），冒号因此对齐且带“空隙”。
% 实现要点（关键！）：
%   * 不能用 \ensuremath 数学模式——数学模式下 xeCJK 不插 CJKglue，字符无法拉伸；
%   * 也不能用 \hss 两端收尾——\hss 会把空隙“吃掉”，只剩自然宽（之前就是这样）。
%   * 正确做法：\hbox to 5.5em{#1} 强制撑满，并把 \CJKglue 设为可无限拉伸，
%     让“字与字之间”的 glue 吸收空隙 → 2 字→大空隙、4 字→小字距，全部撑满 5.5em。
%   * 5.5em ≈ Word 标签单元格宽 87pt（4 字 64pt + 3×8pt 字距）；冒号在盒后，落同一列。
%   * 用 { } 分组，局部改写 \CJKglue，不影响全文其它排版。
% ⚠️ 坑：\CJKglue 在 xeCJK 中是【宏】而不是 register，不能写 "\CJKglue=<glue>"，
%   否则那个 = 会被当作普通字符排进版面（实测每个标签前多出一个 "≈9pt" 的 "="），
%   既难看又挤掉字距。必须用 xeCJK 的键值接口：\xeCJKsetup{CJKglue=...}。
\newcommand{\labelfour}[1]{%
  {\xeCJKsetup{CJKspace=false,CJKglue=\hskip 0pt plus 1fil\relax}%
   \hbox to 5.5em{#1}}%
}
% ---------- 封面/题名页冒号与内容间隔 ----------
% 学位论文模板中冒号后接内容的标准间隔为一个全角空格（约等于汉字宽）；
% \zhqspace 定义为 1em，随字号自动缩放（三号=16磅、小四=12磅）。
\newcommand{\zhqspace}{\hspace{1em}}
% ---------- 封面/题名页「冒号 → 值」列间隔（按 Word 实测） ----------
% Word「附件1：中文题名页」实测：全角冒号右端 302.8pt，值列起点 313.8pt，
% 即冒号后净间隔 10.8pt（三号字 16pt 的 0.675em）。
% ⚠️ 大坑：xeCJK 会对全角标点「：」做标点压缩，在冒号后插入约 -11.7pt（0.73em）
%    的负间距。因此直接写 \hspace{0.675em} 会被吃掉，值反而与冒号重叠
%    （实测：写 0.675em/1em/16pt 时值列起点一律停在 307.2pt，与间距取值无关！）。
% ⚠️ 另注：试图用 \hbox{} 阻断压缩无效——空盒后的 \hspace/\kern 位于盒子开头会被丢弃。
% 故此处【显式补偿】：0.675em（目标间隔）+ 0.73125em（压缩补偿）= 1.40625em。
% 实测效果：值列起点 313.7pt vs Word 313.8pt（差 0.1pt）。
\newcommand{\zhlabelsep}{\hspace{1.40625em}}
